# 《我和女主共用一条命》固定输入

## 游戏企划

- 游戏标题：《我和女主共用一条命》
- 一句话概述：电竞替补苏澄穿成仙侠话本里的恶毒大师姐，拒绝按系统命令羞辱新入门的女主宁照雪后，两人被绑上共享伤痛的共命红环；她们必须在当日试剑大会结束前决定继续互害、一起逃走，还是把两个人都写成故事主角。
- 核心目标：苏澄要在试剑大会结束前保住自己和宁照雪的命，并夺回对自身去留的决定权。
- 关键词：穿书、仙侠、恶毒女配、双女主、系统、共命、轻喜剧、热血。
- 体量：中，十五至二十五分钟。
- 结构：共享主线、一次调剂分支、终局三结局，共十二个节点。
- 起：苏澄在现实中长期坐冷板凳，穿书后又被系统命令照稿行动；她拒绝掌掴宁照雪，两人被共命红环绑在一起。
- 承：两人以不同信任状态进入试剑大会，在共同受伤和配合中拿下试炼，第一次尝到由自己行动获得的胜利。
- 转：掌门利用她们的共命唤醒同生剑，系统同时要求苏澄按原剧情死在宁照雪剑下；此前合作成果变成逼她们互杀的工具。
- 合：两人闯入命盘殿，选择切断关系返回现实、保留共命离开宗门，或把两人的名字同时写入天命卷。
- 结局：回到替补席；共命下山；双主角改命。
- 主题：当一个故事只允许一个主角时，被安排成对手的人能否拒绝互害，共同争取选择权。

## 世界规则

1. 苏澄穿入自己玩过的仙侠剧情，系统通过黑色剧情玉牌向她发布即时命令；初期只有她能看见文字和听见系统声。
2. 苏澄拒绝第一次命令后，她与宁照雪腕上出现共命红环。一方受到的疼痛和真实伤势会同步到另一方；相距超过三十步，红环开始灼痛。红环不共享思想和记忆。
3. 共命不是情感认证，只是一条强制规则。两人配合越准确，越能共同驱动原本需要一人献祭才能唤醒的同生剑。
4. 系统的终点任务是恢复原剧情：宁照雪在试剑大会上杀死恶毒大师姐苏澄。任务完成，苏澄可返回现实。
5. 命盘殿保存天命卷、断命剪和一次性归途符。断命剪可以切断红环，但会删除双方关于彼此的记忆；归途符送苏澄回现实。两人也可共同在天命卷主角位签名，使系统失去单主角控制权。
6. 奇幻规则只通过红环灼痕、同步伤势、玉牌文字、同生剑双刃和天命卷改字表现，不增加临时能力。

## 角色描述

### 苏澄

- 二十四岁，现实中是职业电竞队替补，反应快、擅长临场配合，但长期没有上场决定权。
- 穿书身份为凌霄宗大师姐，也是原剧情中负责羞辱女主、最终被女主杀死的恶毒配角。
- 说话直接，紧张时会先处理眼前问题，不爱发表大道理；面对不公平安排容易顶嘴。
- 起初只想活着回现实，后来不愿用宁照雪的孤立和记忆换取自己的退路。

### 宁照雪

- 十九岁，出身普通，以第一名通过凌霄宗入门考核，却因没有家世被安排成受辱的新弟子。
- 警惕、自尊强，不轻易接受苏澄突然示好；习惯先确认事实，再决定是否合作。
- 她最怕再次被别人替她决定去留。对苏澄的关系从防备、被迫合作，发展为能够共同承担选择。

### 魏无尘

- 凌霄宗掌门，五十余岁，外表温和，实际把弟子和剧情规则都视作维持宗门声望的工具。
- 他知道共命红环能唤醒同生剑，故意让两人进入试剑大会并在终局安排互杀。
- 说话简洁、讲现实结果，不用玄虚格言；当控制失效时会直接下令阻止。

### 白婆婆

- 宗门药庐管事，六十余岁，负责给弟子验伤。见惯宗门规矩，不替任何人作决定。
- 她用实际测试说明共命规则，只说自己能确认的事情。

### 系统声

- 没有人格情感，只发布任务、倒计时、奖励和失败后果。用简短、明确的功能语句。

## 场景描述

### 电竞馆后台

- 当代比赛后台，主舞台声浪隔墙传来，替补席与上场通道只隔一道门。
- 用于建立苏澄长期等待别人决定自己是否上场的现实处境。

### 凌霄宗入门台

- 山门前石台，数十名新弟子列队，掌门与大师姐位于高阶。
- 用于首次系统命令、苏澄拒绝羞辱宁照雪和共命红环出现。

### 药庐

- 木架、药炉和诊台构成的实用空间；后门直通试剑林。
- 用于以针刺、距离和药布测试共命规则，并建立首次选择。

### 试剑林与断云桥

- 林中设有机关木鸟、落石阵和横跨深谷的旧索桥；终点插着两枚试炼令。
- 用于两条信任路线的即时差异、共同受伤、协作和首次胜利。

### 试剑台

- 宗门公开擂台，中央石槽封着双刃同生剑，四周有锁阵。
- 用于掌门利用两人的配合成果，强迫她们完成原剧情互杀。

### 命盘殿

- 试剑台下方旧殿，墙上悬着不断自行改字的天命卷；供桌上放断命剪和归途符。
- 用于最终选择与三个结局。

## 道具描述

### 黑色剧情玉牌

- 苏澄穿书后随身出现，正面浮出系统任务、倒计时和返回条件；任务失败时牌面开裂并触发惩罚。

### 共命红环

- 分别缠在苏澄和宁照雪左腕，同步疼痛、伤势和距离灼痛；不能传递思想。切断后双方忘记彼此。

### 同生剑

- 试剑台石槽中的双刃长剑，两人动作同步才能拔出和使用；掌门原计划让胜者以另一人的命完成认主。

### 天命卷、断命剪与归途符

- 天命卷规定单一主角和既定死亡节点；断命剪切断红环并删除共同记忆；归途符只能使用一次，将苏澄送回现实。
