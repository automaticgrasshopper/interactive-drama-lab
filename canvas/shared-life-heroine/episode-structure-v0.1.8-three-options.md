# 《我和女主共用一条命》三种分支拓扑方案

以下三案使用同一人物、世界和终局，只改变第二集“打／不打”被识别后如何展开。

## 方案一：教学死路型

不改变“拒绝掌掴才触发共命”的既有规则。第一处选择直接告诉玩家：服从系统虽然暂时安全，却会失去后续行动权。

```mermaid
flowchart TD
    A01["第1集 替补上场"] --> A02{"第2集 打还是不打"}
    A02 -- "执行命令，掌掴宁照雪" --> A03["小结局 被剧情接管"]
    A02 -- "拒绝命令，放下手" --> A04["第3集 共命惩罚"]
    A04 --> A05["第4集 疼在两个人身上"]
    A05 --> A06{"第5集 是否坦白系统"}
    A06 -- "告诉宁照雪全部真相" --> A07["第6集 把话说开"]
    A06 -- "只说明共命规则" --> A08["第7集 瞒不住的伤"]
    A07 --> A09["第8集 两个人的第一名"]
    A08 --> A09
    A09 --> A10["第9集 拒绝互杀"]
    A10 --> A11{"第10集 把名字写在哪里"}
    A11 -- "剪断红环，返回现实" --> A12["主结局 回到替补席"]
    A11 -- "烧毁归途符，共命下山" --> A13["主结局 共命下山"]
    A11 -- "共同签写天命卷" --> A14["主结局 两个主角"]
```

结构特点：改动最小；第一选择有明确生死压力；“打”线只有一个结果节点，复玩内容较少。

## 方案二：带差异快速汇合型

把共命红环调整为入门台隐藏的同生印：第一次身体接触或共同承受阵法判定都会激活。系统只决定激活方式，不决定红环是否存在。两条路线都进入主线，但带着不同关系与系统状态汇合。

```mermaid
flowchart TD
    B01["第1集 替补上场"] --> B02{"第2集 打还是不打"}
    B02 -- "执行命令，掌掴宁照雪" --> B03A["第3A集 她记住了这一巴掌"]
    B02 -- "拒绝命令，放下手" --> B03B["第3B集 她替我受了惩罚"]
    B03A --> B04["第4集 同生印被激活"]
    B03B --> B04
    B04 --> B05["第5集 疼在两个人身上"]
    B05 --> B06{"第6集 是否坦白系统"}
    B06 -- "坦白系统" --> B07A["第7A集 低信任：拿证据说话"]
    B06 -- "隐瞒系统" --> B07B["第7B集 共同受伤后追问"]
    B07A --> B08["第8集 断云桥合作"]
    B07B --> B08
    B08 --> B09["第9集 两个人的第一名"]
    B09 --> B10["第10集 拒绝互杀"]
    B10 --> B11{"第11集 把名字写在哪里"}
    B11 -- "剪断红环" --> B12["主结局 回到替补席"]
    B11 -- "保留共命离开" --> B13["主结局 共命下山"]
    B11 -- "共同改写天命" --> B14["主结局 两个主角"]
```

结构特点：两项选择都能继续；汇合快、制作量可控；需要调整共命装置的触发规则，并在后续持续承接“打过她／替她反抗”的关系差异。

## 方案三：多级编织带型

保留“第一次拒绝系统才触发共命”。玩家若先选择掌掴，系统会在下一阶段提出更严重的命令；玩家仍有机会反抗并进入共命主线，也可能继续服从而走向小结局。

```mermaid
flowchart TD
    C01["第1集 替补上场"] --> C02{"第2集 打还是不打"}
    C02 -- "掌掴宁照雪" --> C03A["第3A集 系统奖励，宁照雪敌视"]
    C02 -- "拒绝掌掴" --> C03B["第3B集 惩罚降临，立即共命"]

    C03A --> C04A{"第4A集 是否毁掉宁照雪的剑"}
    C04A -- "执行第二道命令" --> C05D["小结局 照着剧情活下去"]
    C04A -- "夺回剑并拒绝系统" --> C05A["第5A集 延迟共命：她不相信我"]

    C03B --> C04B{"第4B集 是否坦白系统"}
    C04B -- "坦白全部" --> C05B["第5B集 共命同盟"]
    C04B -- "隐瞒系统" --> C05C["第5C集 被迫合作"]

    C05A --> C06["第6集 试剑林：三种信任状态汇合"]
    C05B --> C06
    C05C --> C06
    C06 --> C07["第7集 断云桥兑现状态差"]
    C07 --> C08["第8集 两个人的第一名"]
    C08 --> C09{"第9集 接受互杀还是共同破局"}
    C09 -- "接受系统交易" --> C10D["小结局 只剩一个主角"]
    C09 -- "共同破坏试剑台" --> C10["第10集 进入命盘殿"]
    C10 --> C11{"第11集 把名字写在哪里"}
    C11 -- "剪断红环" --> C12["主结局 回到替补席"]
    C11 -- "保留共命离开" --> C13["主结局 共命下山"]
    C11 -- "共同改写天命" --> C14["主结局 两个主角"]
```

结构特点：最完整地兑现“服从／反抗”主题；第一次选择不会被浪费，后续还能形成二次反讽；节点和剧本制作量最高，汇合节点必须真实承接三种信任状态。
