# 《请保持通话》大纲重构说明

## 这次解决什么

上一方案难懂的主要原因不是句子，而是同一时间要求观众理解关系锚点、人格密钥、时间线覆盖、研究所阴谋、三段关系和记忆牺牲。新方案把抽象层全部拿掉，只保留一条肉眼可见的因果链：

```text
过去是否承担责任
→ 妹妹是否参加电网考试、朋友是否留在气象行业
→ 2038 年危机中谁在岗位、谁有权限、谁愿意回应
→ 三项同步操作能否完成
→ 世界是否获救
```

## 结构取舍

- 核心关系从三段减为两段：兄妹、友情。
- 穿越点从三个减为两个，而且都固定在录音里。
- 世界危机不在开场讲，先让观众理解“他亏欠了谁”。
- 关系不再是超自然规则，也不承担密码或能源功能。
- 每次关系选择都有立刻可见的现实反馈，不等到结尾解释。
- 最终只要求记住一条规则：切电、开冷却、拔核心必须同时完成。
- 真结局不等于被原谅，只说明三个人愿意共同完成眼前的事。

## 情绪脊如何影响故事

“起”先让程野处于孤立和无补救权；“承”给他两次回去行动的希望，但压住即时原谅；“转”用三项同步操作证明一个人无法控制全部；“合”的翻盘必须由玩家此前承担责任、此刻主动求助共同促成。

因此，情绪脊只决定压力、希望、失控和夺回行动权的次序，没有把 PAD 数字、实现概率或主题术语塞进人物对白。

## 下一步建议

先只审这份正式输入，重点确认三件事：

1. 两段过去是否一看就懂程野当年错在哪里。
2. 两个人为什么会出现在最终岗位，因果是否自然。
3. 三项同步操作是否足够直观，不需要额外解释。

确认大纲后再进入分集；不建议现在先写剧本或润色台词。
