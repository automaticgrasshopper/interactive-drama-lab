# 全局事实

## 故事前提
暴雨夜，民俗记者沈砚接到失踪七年的姐姐沈青梧来电，在天亮前进入与临江市重叠的里城，追查无名尸案与除名仪式。

## 事实基线
沈青梧七年前为救沈砚偷换两人姓名并成为无名者；裴玄度长期主持除名仪式并借改名延寿；柳含章守护里城入口；周既白调查无名尸案。

## 世界规则与代价
亡者只留最后一句可能失真的遗言；里城只在子时至寅时显现；禁术以一段真实记忆为代价；名字同时从现实记录、亲友记忆与城隍簿删除后，人会落入里城。

## 主干情绪脊
由姐姐失而复得的希望进入追索；由证词冲突与记忆损失转入怀疑；由身份偷换真相造成亲情背叛；终局在亲情、真相与城市代价之间选择。

## 结局条件
公开名册进入昭告全城；接过城隍印进入无名守城；掌握完整名册、裴玄度真实姓名与城隍印裂纹后可改写因果。

## 场景固定连接
旧城区北端连接子时地铁；纸扎铺位于旧城区左侧；地铁与里城暗河相通；民俗档案馆保存纸证与名册；暗河东侧门连接城隍旧庙。

## 全局未解决冲突
姐姐为何失踪；遗言是否可信；献祭能否终止；终止后城市会承担什么；沈砚愿意失去什么。
