# 《夜行无名》第一集内容测试

测试日期：2026-07-17

## 第一集《雨夜来电》

单集梗概：暴雨夜，追查连续无名尸案的民俗记者沈砚接到失踪七年的姐姐沈青梧来电，随后在第四名死者身边听见“青梧在站里”的亡者遗言，并看见死者腕上的褪色红线逆着积水伸向封闭地铁口，迫使他决定是否把遗言告诉负责现场的刑警周既白。

【场一 · 临江旧城区南侧牌坊 · 暴雨夜 · 外】
出场：沈砚、沈青梧（电话声）

△ 暴雨压过骑楼。沈砚穿过南侧牌坊，停在警戒带外。他的深灰防水夹克已经湿透，旧记者包护在胸前。

△ 手机振动，屏幕上没有号码。沈砚接通电话。

沈砚：喂？

沈青梧：小砚。

△ 沈砚转身背向现场，用手挡住听筒上的雨。

沈砚：姐？你还活着？

沈青梧：今晚，别让任何人记住我。

沈砚：你在哪儿？

沈青梧：别找我。

沈砚：沈青梧，你先说地点。

△ 电话里传来一声沉闷的金属铃。通话中断。

△ 沈砚立即回拨。手机只剩忙音。他把手机调成飞行模式，打开录音笔，望向警戒带内被雨布遮住的担架。

【场二 · 临江旧城区路灯下 · 连续 · 外】
出场：沈砚、周既白

△ 负责无名尸案的刑警周既白从担架旁走来，横移半步挡在警戒带缺口前。

周既白：沈砚，退后。

沈砚：我只看一眼。

周既白：你每次都这么说。

沈砚：这是第四个？

周既白：消息还没出去。谁告诉你的？

沈砚：你没否认。

周既白：你写民俗的，少拿记者那套来套我。

△ 两名现场人员抬起担架，从两人身后经过。雨布被风掀开一角，露出死者垂下的左手。腕上缠着一圈褪色红线。

△ 沈砚忽然侧头屏息。周围雨声像被推远，只剩一个贴着耳边的沙哑男声。

亡者遗言：青梧在站里。

△ 沈砚一把抓住担架边缘。周既白扣住他的手腕，示意现场人员停下。

周既白：你认识死者？

沈砚：不认识。

周既白：那你抓什么？

△ 沈砚没有回答。他盯着死者腕上的红线。浸了雨的线身正一点点变成暗红。

沈砚：前三个死者，也有这种线？

周既白：你看过物证照片？

沈砚：有，还是没有？

周既白：有。

△ 担架再次抬起。一截断开的红线从雨布下落进积水。路面积水向南流，红线却慢慢绷直，逆水滑向北侧封闭的地铁口。

△ 周既白蹲下，用证物镊去夹。红线从镊尖下滑过，钻进地铁卷帘门下的缝隙。

沈砚迈过警戒带。

周既白起身拦住他。

周既白：沈砚。你刚才到底听见了什么？

△ 沈砚看向周既白，又看向北侧封闭的地铁口。手机屏幕只留下一条没有号码的通话记录。

你怎么做？

- 告诉周既白“青梧在站里”。
- 追向封闭地铁口。

## 校对结论

### 第一集前提

- 主角：沈砚，追查连续无名尸案的民俗记者。
- 到场原因：持续追查同类案件，赶到第四名死者现场。
- 当前目标：确认姐姐来电是否真实，并找出她的位置。
- 主要关系：周既白负责现场，认识沈砚但限制他接触证据。
- 核心异常：死者遗言与逆流红线同时指向封闭地铁站。
- 核心能力：沈砚在死者经过时听见亡者最后一句话。
- 主要悬念：沈青梧是否真的在地铁站里。

### 中文对白

- 普通追问、拒绝、套话和回避占多数。
- 承重信息分散在来电、遗言、红线和周既白的回答中，没有连续解释世界规则。
- 沈砚短促直接，周既白稳定且带现场控制感，人物语体可区分。
- 周既白先阻止沈砚，沈砚再用红线逼问，证据逐层改变两人的行动。

### 连续性

- 沈青梧通过手机来电，纸扎手机尚未出现，未混淆道具来源。
- 褪色红线首次出现于死者手腕，浸水变深并指向地铁口，符合既定状态。
- 未提前使用禁术，因此没有遗漏记忆代价。
- 结尾选择发生在周既白追问与地铁入口打开下一行动之后，两个选项均为当下可执行动作。

校对结果：通过。
