## 二、已经完成但尚未提交的工作

### 1. 后台持续生产框架

- 新增 `backend/production_worker.py`，将大纲拓扑、逐集剧本生成和逐集校验放到本机后台执行。
- 页面刷新后可通过任务接口恢复运行状态、三阶段进度和已生成结果。
- 生产流程不再把“只生成一场戏”误报成整部完成；只有拓扑、全部剧本和校验都走完才算交付。
- 逐集校验包含机械一致性、因果、对白和独立冷读检查，并按“未通过就返工”的策略继续修订。

### 2. 强制停止

- 后台会保存停止标记，并主动关闭正在等待的 OpenRouter HTTP 连接，不再只是等待当前请求自然结束。
- 大纲页按钮改为“■ 强制停止”，点击后会等待后台确认停止，再恢复页面可操作状态。
- 生产后台也支持停止任务。
- 已用阻塞响应单元测试验证主动断开；也在真实卡住的 OpenRouter 请求上验证过，页面最终显示“后台生产已停止”。

### 3. 长请求与超时处理

- OpenRouter 长结构化输出的读取窗口调整为 20 分钟。
- 如果流式连接超时，但 `===JSON===` 后已经收到完整合法 JSON，会抢救并继续处理；截断 JSON 仍会报错，不会当作成功。

### 4. 大纲编剧台

- 三层生产进度：拓扑与情绪结构、全部分集剧本、最终校验。
- 分集流程图支持放大、缩小和适配画布。
- 刷新页面不会主动终止后台生产；可恢复任务状态。
- 大纲页保留生成记录的只读查看入口、Git 状态展示和“生成分镜”能力；推送、删除等管理动作集中到生产后台。
- 顶部多余的记录/刷新按钮和无意义的扩展入口已按此前要求移除或收拢。

### 5. 生产后台与任务管理

- 后端 API 版本已提升到 `5`。
- 支持汇总全部项目任务，不只展示当前页面或尚未进入 Git 的任务。
- “本次项目 / 全部任务”使用页签展示。
- 任务条目可显示 CG、Git 和归档状态，详情按需展开。
- 删除任务会二次确认；若任务已进入 Git，会删除当前分支中的对应文件并推送删除，但不会改写 Git 历史。
- 项目管理按钮合并为“推送到 Git”：先获取远端、提交项目数据、合并远端更新、再推送。
- Git 文本冲突可调用已配置的 OpenRouter 模型做三方合并；额度不足或自动合并失败时会中止并明确提示“有冲突，提交失败”。
- 后台支持识别操作系统并精准重启当前工作台服务，只针对本项目的解释器和 8000 端口。
