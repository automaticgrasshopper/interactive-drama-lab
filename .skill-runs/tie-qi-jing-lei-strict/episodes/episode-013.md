# 分集编号

episode-013

# 分集标题

归途

# 分集剧本

## 单集梗概

沈砚秋在双方解除威胁姿态后把核心装回玄甲-07，霍峥率军挡住赫连朔，为它争取穿越时间。坦克返回未来并从另一侧关闭裂隙，雁回关依靠提前撤离避开覆灭。霍峥最终以古代军队自己的力量继续守城。

## 完整剧本

【裂隙核心区·黎明·外】

霍峥抬起空手，先让陆骁命骑兵收弓，再将自己的雁翎将军剑收入鞘中。玄甲核心模块已经交到沈砚秋手里，守军也都退出车体的攻击范围。

霍峥：核心还给它。所有人只守路，不碰车。

陆骁盯着北口的狼旗。

陆骁：赫连朔不会跟我们一起收刀。

霍峥：所以你守的是沈砚秋装回核心的这几步。不是去赢他。

沈砚秋抱着六棱柱走向尾舱。玄甲-07只剩备用动力，炮塔低垂，无法自行开启变形的第二道锁扣。她先插入模块，再把未来残像终端的圆形接口接上舱壁。第一道锁扣闭合，第二道仍卡住。

赫连朔抬手，北口弓手拉满弓弦。

赫连朔：霍峥，你放它走，午后拿什么守城？

霍峥拔出雁翎将军剑，这一次没有走向玄甲-07，而是站到沈砚秋身后，面对北口。

霍峥：午后的仗，午后用我们自己的命打。现在这件东西不属于你，也不属于我。

陆骁带骑兵并排挡在南坡。赫连朔放箭，骑兵以盾接住第一轮。霍峥没有下令冲锋，只让阵线一步不退。沈砚秋用终端反复校正锁扣，额角被飞石擦破，手仍稳在接口上。

沈砚秋：再给我十息。

陆骁：你只管数，我给你十息。

陆骁下马，把盾插进地面。第二轮箭落下时，玄甲核心模块终于被锁紧。玄甲-07全车灯光重新亮起，炮塔先转向北口，又在识别到阵前百姓后压低武器姿态。

玄甲-07：自主任务恢复。非战斗人员撤离路径建立。

它没有攻击赫连朔，而是用车体撞开东侧一段松动石壁。碎石落下，形成一面隔开弓阵的屏障。被截百姓沿屏障后的窄路跑向南坡，陆骁带人逐一接走。

赫连朔失去人质，立刻命前军压上。霍峥率骑兵守住窄路，不追出屏障，只把每一次冲击挡回北口。

玄甲-07驶入焦黑环形地痕。裂隙中的未来试验场短暂变得清晰，它的履带在古代泥土和未来金属地面之间各留下一半印痕。

玄甲-07：撤离完成。感谢协助。

霍峥：回去吧。把你们的门，从那边关上。

玄甲-07穿过冷蓝裂光。终端上的环形倒数归零，随后彻底熄灭。裂隙从中央向内折叠，北口军阵和古代旗帜的影子重新只剩一重。

赫连朔看着空下来的焦黑地痕，命前军停止。他没有得到坦克，霍峥也没有。双方重新回到同一种兵刃能够决定胜负的战场。

赫连朔：你把能赢的东西送走了。

霍峥：我把不该输给我们的时代送回去了。

【雁回关城楼·清晨·外】

撤离百姓已经进入西山安全地带。沈砚秋合上伤亡名册，名册里没有再增加被未来兵器夺走的名字。陆骁把残破赤旌重新插回中央军旗座，随后回到北侧城垛。

荒原上，玄甲-07的履带印在裂隙消失处中断，只剩雁回关骑军的马蹄印一路返回城门。

陆骁：赫连朔在重新列阵。我们还是兵少。

霍峥扶住有缺口的城垛，看了一眼城内空下来的街巷。

霍峥：人已经撤走，城就只是城。守得住就守，守不住就退到下一道关。今天不拿百姓换胜负。

沈砚秋走下南侧石阶，继续带最后一队伤兵出城。霍峥与陆骁留在城楼，等荒原上的战鼓再次响起。

# 剧本分析

## 本集冲突

霍峥主动放弃对未来武器的占有，以解除兵刃和正面防守为沈砚秋争取归还核心的时间。玄甲-07恢复自主任务后先救出百姓，再返回未来关闭裂隙；雁回关失去技术优势，却保住了决定自身战争方式的权利。
