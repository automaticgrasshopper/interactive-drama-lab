# 分集编号

episode-012

# 分集标题

钢铁王朝

# 分集剧本

## 单集梗概

霍峥用核心向玄甲-07下达迎敌命令，赫连朔的军阵迅速崩溃。雁回关得救，裂隙却未被彻底关闭；来自王都的使者接管核心，陆骁成为第一支新军的统领，战争开始围绕未来武器重新排列。

## 完整剧本

【裂隙核心区·黎明·外】

霍峥把玄甲核心模块送入尾舱，却没有解除未来残像终端上的外部控制。两道锁扣合上，玄甲-07重新抬起炮塔，冷蓝灯从车尾依次亮到车头。

玄甲-07：自主任务受限。外部指令等待确认。

沈砚秋抓住霍峥的手腕。

沈砚秋：这一炮出去，裂隙会留下。你看见终端里的后果了。

北口弓弦齐响。霍峥推开沈砚秋，用自己的肩甲挡住一支落箭，随后按下终端唯一亮起的攻击标记。

霍峥：目标，北口军阵。打开撤离通道，不追击溃兵。

玄甲-07：指令确认。

炮塔越过跪在阵前的百姓，瞄准后方无人石壁。轰击震塌北口上沿，碎石和烟尘切断赫连朔军阵。陆骁立刻带骑兵从南坡冲入烟尘，先把百姓拉到车体后方，再沿裂开的阵线逼退弓手。

赫连朔的战马受惊，他不得不徒步退向北口。玄甲-07没有追击，却以装甲顶开敌军挡路的拒马。北原军看见古代兵刃无法撼动的巨物听从霍峥号令，前阵先乱，后阵随即向荒原溃散。

陆骁提刀追出数丈，被霍峥喝停。

霍峥：百姓先走。别把他们逼回裂隙。

赫连朔隔着烟尘回望。

赫连朔：你已经用了。下一次，你不会舍得放下。

裂隙没有闭合。玄甲-07的攻击能量让冷蓝光稳定成一道细缝，里面不时闪过未来战场。终端显示核心只能维持车体，已经没有足够能量同时封闭通道。

【雁回关城楼·数月后·日·外】

城墙已经修补，玄甲-07停在北侧城门内。它的炮塔被木架和铁链固定，尾舱外站着王都派来的工匠。工匠不懂内部原理，只能照着每一处外形拆画图样。

沈砚秋把新的伤亡名册放到霍峥面前。名册比大战前厚了三倍，死者不再只来自北境，还包括争夺坠落设备的各路军队。

沈砚秋：王都又从裂隙边捡回一块残骸。使者说，谁私藏图样，按叛国论。

城下，陆骁换上新制重甲，正训练一支护送玄甲-07的骑军。他没有得意，只反复检查士兵与履带之间的距离。

陆骁：停机时先清路。谁再靠近车头，军法处置。

霍峥望向沙盘。过去代表赫连朔的狼旗已经倒下，更多陌生旗标却围在雁回关四周。王都的使者从他手中接过未来残像终端，要求他在新的军令上盖印。

使者：陛下赐名钢铁新军。霍将军守关有功，自今日起，雁回关不再只守北境，也替王朝看守天门。

霍峥没有去碰印泥。城外远方，那道没有关严的冷蓝细缝再次亮起。玄甲-07的灯随之苏醒，炮塔在铁链中发出低沉转动声。

# 剧本分析

## 本集冲突

霍峥把夺来的控制权用于眼前战争，并通过限制追击救下百姓、击退赫连朔；但攻击耗尽了封闭裂隙的机会。胜利使未来技术被王朝制度化追逐，陆骁与霍峥都开始承担更漫长的失控后果。
