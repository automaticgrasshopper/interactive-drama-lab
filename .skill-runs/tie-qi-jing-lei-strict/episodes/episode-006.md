# 分集标题

百年残像

# 分集剧本

## 单集梗概

霍峥等人从终端残像中看见百年后的无人战争，也第一次确认坦克编号为“玄甲-07”。它追踪的不是雁回关，而是即将在荒原深处扩张的裂隙。赫连朔派人索要终端，逼霍峥决定与机器合作，还是先夺取其核心。

## 完整剧本

【断烽峡谷·黎明前·外】

沈砚秋把未来残像终端放在南口一块平石上。玄甲-07停在一丈之外，霍峥和陆骁守在终端两侧，谁也没有再向它举起兵器。

终端电量将尽，沈砚秋用布擦净背部圆形接口，再将它对准巨物尾部。冷蓝光接通，两件设备同时亮起。

投影中，一个穿陌生防护服的人站在同样的暗灰车体旁。画面没有清楚文字，声音却还能辨认。

记录声：玄甲零七，撤离任务确认。异常通道将在雷暴峰值后稳定。不得追击失去战斗能力的目标。

霍峥看向巨物。此前让路、停火和撤离警告第一次有了共同来源。

霍峥：玄甲-07。那是你的名字？

玄甲-07：单元编号……确认。

投影继续。未来城市上空出现一道蓝白裂隙，无人兵器被吸入其中。画面切到地图般的光影：一个光点代表玄甲-07，另一个扩张的圆环位于荒原北偏东。圆环稳定后，雁回关恰好落在能量扫过的边缘。

沈砚秋：它催人撤离，不是因为它要攻城。下一次雷暴来了，城会先被那道裂口碰到。

陆骁盯着画面里成排倒下的城墙。

陆骁：也就是说，只有它知道怎么关。可它若临阵转向，我们连它的腿都拦不住。

玄甲-07尾部维护舱缓慢打开。舱内是一枚四十厘米长的黑灰六棱柱，两侧有机械锁扣，中央蓝色灯带与车体同步闪动。

玄甲-07：核心模块。任务记录。控制权限。封闭通道需要……核心完整。

东壁上方忽然落下一支没有箭头的信箭。箭上绑着赫连朔的黑皮手套和一张素帛。

陆骁展开素帛。

陆骁：赫连朔截住了从东坊撤走的三户百姓。他要我们日出前把终端和铁兽送到核心区北口。

紧接着，峡谷外传来赫连朔平缓的声音。他没有进谷，只让声音越过落石。

赫连朔：霍峥，你守了一辈子城，今夜却有一件东西能让你永远不必再守。你若不用，我就替你用。

玄甲-07的炮塔转向北口，尾舱锁扣却因旧损反复弹开。终端投出两种有限方案：由它向沈砚秋开放临时授权，允许她在必要时取出核心并完成封闭；或者由人强制拆下核心，以地形限制车体，再用终端下达命令。

沈砚秋：合作不等于把命交给它。终端在我手里，我能看见它每一步要做什么。

陆骁：权限在核心里。把核心拿下来，它走哪一步，才该由将军决定。

裂隙方向又亮了一次，峡谷石壁蒙上冷蓝反光。玄甲-07的尾舱保持开启，陆骁的铁钩和沈砚秋的终端同时停在核心模块前。

# 剧本分析

## 本集冲突

终端把坦克的身份、任务和裂隙风险连成可验证事实，也暴露核心模块同时承载任务和控制权。赫连朔以百姓逼近，使霍峥必须在有限合作与强制夺控之间决定谁掌握行动主动。
