# 分集标题

同路异心

# 分集剧本

## 单集梗概

玄甲-07允许沈砚秋携带核心模块同行，并以有限投影标出裂隙位置。霍峥留下陆骁继续疏散，自己与玄甲-07赶往核心区；赫连朔则押着被截住的百姓从北侧追来。

## 完整剧本

【断烽峡谷·黎明前·外】

霍峥让士兵退到南口，自己和沈砚秋走向玄甲-07的尾舱。炮塔没有转向他们，冷蓝状态灯由急促闪烁变为缓慢明灭。

霍峥：你把关闭裂隙的办法交给她。我们替你清出到核心区的路，也把那里的人撤走。

玄甲-07：临时授权对象……沈砚秋。任务冲突时，平民撤离优先。

两侧锁扣依次松开。沈砚秋双手托出玄甲核心模块，四十厘米长的六棱柱比她预想得更沉。终端投影显示：维护舱锁扣受损，途中若再次震动，核心可能脱落；模块离舱后，玄甲-07只能依靠短时备用系统行进，不能使用主要武器。

陆骁：它把自己的命交出来，是因为信我们，还是因为它已经没别的办法？

沈砚秋：都不是。它算过谁最可能把百姓带出去，所以选我。机器也会留后手。

霍峥：我们也留。陆骁，你带骑军回关，护住东坊撤离队。没有我的令，不许追赫连朔。

陆骁握紧护腕。

陆骁：将军，你只带医官跟一件停了炮的铁甲去见他？

霍峥：你守的是活人，不是我的面子。把人送走，再来找我。

陆骁看了一眼沈砚秋怀里的核心，最终把刀收入鞘中，带骑兵向南离开。

【裂隙核心区·黎明前·外】

玄甲-07沿南侧坡道缓慢下降。它失去主要动力控制后，每次跨过碎石都要先停顿校正。沈砚秋把核心接到未来残像终端背部，屏面投出一条通往中央裂隙的窄路线。

圆形洼地中央只有一道细长冷光，东侧散落着终端影像中见过的未来设备残骸。那些残骸时隐时现，证明这里正与百年后的战场重叠。

沈砚秋：核心离开它以后，裂隙的倒数快了一倍。必须在中央重新决定，是让它接回核心，还是把核心留在这里烧尽。

北侧窄出口传来马蹄。赫连朔先走入冷光，摘下右手黑皮手套。他身后是被截住的三户百姓，敌军只用长枪挡住退路，没有伤人。

赫连朔：你果然会把最危险的东西交给最不想杀人的人。沈医官，把它给我，我让这些人回城。

霍峥挡到沈砚秋和百姓之间，雁翎将军剑仍未出鞘。玄甲-07调整车身，用装甲遮住南侧坡道。

玄甲-07：非战斗人员。撤离路径……建立。

赫连朔的笑意消失。裂隙骤然升高，蓝白光扫过所有人的脸。

# 剧本分析

## 本集冲突

合作让沈砚秋获得核心模块和任务信息，也使玄甲-07暂时放弃主要武器与自保能力。霍峥必须分兵保护百姓，最终以更少兵力和脆弱合作关系面对赫连朔。
