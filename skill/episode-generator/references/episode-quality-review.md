# 逐集独立复检

本 reference 只在正文与人话复写完成后加载一次，不参与拓扑和写作；只供不知道作者计划的普通观众判断正文能否独立成立。

## 一、冷读输入

只读取当前路径的有限前情、最终正文和正式资产；不读生产卡、作者意图、后续剧情、预期答案、初稿评价或旧结论。复检绑定正文 SHA-256；一字变化，旧结论失效。

## 二、先过理解门

合上作者解释，仅凭冷读输入，用普通话分别复述：

1. **人物任务**：谁以什么身份或关系在场，此刻必须做什么？
2. **触发代价**：什么异常或压力打断任务，不处理或做错会怎样？
3. **行动结果**：谁因此采取什么行动，遇到什么阻力或调整，造成什么可见结果？
4. **下一入口**：结尾逼出什么立即行动、具体问题或真实选择？

四项须能从正文指出依据。任一项只能靠设定脑补、抽象主题回答或写“正文不清楚”，立即判理解失败并定位缺环，不用后续七项圆场。身份、规则和代价交代到足以理解当前行动即可。

## 三、理解通过后做七项完整覆盖

逐场通读，不抽样：

1. **事实来源与知情**：人物、地点、权限、证据、装置和物件来源成立；人物只用此刻已知信息。
2. **首次出现与必要交代**：按当前观看路径判断首次出现的人物、组织、地点、能力和关键名词；用动作、称呼、证据或自然反应交代是谁／是什么、与眼前事情的关系及为何此刻需要知道，姓名须有可懂来源。
3. **因果相邻与可见后果**：事件先被感知，再引发符合欲望、压力和能力的反应、行动、阻力、调整及可见结果；不跳过必要接触、移动、失败尝试和代价。
4. **话茬与现场目的**：问题、命令、请求和指责得到回答、拒绝或可识别的回避；台词回应眼前的人事，不替作者发布剧情或主题。
5. **口语组织与反过度压缩**：普通关系话轮不能连续只剩最短骨架；保留有作用的对象、承接、态度和关系指向。危急口令、无线电协作、程序确认及被相邻内容接住的事实短答可以短，不机械补语气词。
6. **普通话表达与叙述可读**：台词与描述分别顺读并各举一处证据。台词用日常语序；描述写清谁做什么、对象和位置怎样变化、前后为何相连。避免生硬倒装、名词堆叠、字幕压缩、作者金句和抽象判断代替画面；题材词可保留，句法仍须直接可懂。
7. **结尾画面与下一入口**：落在可拍动作、位置或物件变化、信息暴露或迫近压力上，并能进入冻结拓扑的直接后续，不用总结代替结果。

## 四、判定与返修

复检只判不改。问题须写明所属层、位置及观众为何不懂或不信；正常内容不逐句报通过。理解门或七项任一失败即不通过；个人风格、短句、留白或人物不讨喜不能单独判错。只修登记缺环，不顺改拓扑、选择、状态、结局或无关场次；修后用新正文完整重跑。理解门通过、七项覆盖、问题为空且指纹一致，才可冻结、组装或回写。
