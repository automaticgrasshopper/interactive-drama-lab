# 剧本执行与逐集校验规范

本文件只在根据冻结生产卡写完整剧本时读取。它合并场次流动、题材化、制片格式和逐集质量校验的必要规则，不参与第一轮拓扑设计。

## 一、规则优先级

发生冲突时按以下顺序处理：

```text
观众看懂
> 场景有戏
> 人物说人话
> 制片格式正确
```

低优先级不得破坏高优先级。结构、前史或人物关系有问题时返回生产卡，不用台词或旁白补洞。

## 二、先写连续戏

不要直接对着动作与台词模板逐行填充。先把一场戏写成连续因果：

```text
人物为当前目标采取行动
→ 对方基于自身目标阻挡或回应
→ 动作和台词迫使下一次反应
→ 信息、关系、权力、目标或风险发生变化
→ 本场结果推动下一场
```

每场至少发生一次可指认变化。只有一个动作和一句反应时，应与相邻内容合并或继续展开。

新人物首次出现时自然交代出场动作、身份锚和来意。场景首次使用时说明人物为何进入；道具首次出现时交代原位置、发现者或取得过程。

## 三、关键情节与题材辨识

承担互动、反转、高潮或分集落点的关键情节必须同时具备：

1. 可见、可信、可拍摄的具体事件；
2. 只在当前题材和既有规则下成立的反差物；
3. 由人物行动造成的规则内升级；
4. 能推动下一场或下一集的结果、问题或选择。

关键反转必须来自“既有铺陈触发行动，行动造成反差结果”的连续因果。不得用无关突发事故、临时新增规则或新人物替代反转。

第一集应让主角的核心能力或核心做事方式在具体事件中发挥作用，并让观众看懂主角身份、当前目标和主要关系。

## 四、中文对白

具体对白以 `chinese-dialogue-craft.md` 为准。写作时执行：

- 普通搭话、确认、追问、拒绝、回避、复述、迟疑和反应占多数；
- 承重句只放在举证、揭露、关系变化、规则说明、条件和决定处，不超过一场台词的三分之一；
- 连续三句都在发布背景、规则、秘密或结论时，拆回有目标和抵抗的正常来回；
- 每句重要台词都回应前一个动作或台词，并推动对方行动；
- 不同人物依据身份、关系、欲望和声音气质形成不同说话方式；
- 悬疑、古装、危险关系和奇幻题材不等于短句、机锋、谜语或海报句堆叠；
- 功能信息必须一遍听懂，悬念只保留具体问题的答案。

## 五、真人样例对照

每集初稿完成后同时读取：

- `chinese-dialogue-craft.md` 中与当前题材或关系最接近的公开素人短剧片段；
- `gold-sample-episode.md` 中《盛世天下·女帝篇》“刘熙的条件”。

只比较方法，不复制台词和情节。

对照素人语料检查：

- 人物是否围绕眼前具体事情说话；
- 是否存在来意、拒绝、追问、劝说、改口和反应；
- 熟人、陌生人、上下级和对手的口气是否不同；
- 是否像真实中文交流，而不是轮流吐露资料。

对照金标检查：

- 每个人当下目标是否明确；
- 对方抵挡后才亮出更硬证据，而非一次倒完背景；
- 证据是否改变权力和行为；
- 互动是否从具体条件与代价中自然产生。

## 六、逐集双校验

每集写完后先保存初稿，再分别执行两类校验。

### 中文对白校验

检查：

- 承重句是否过量；
- 是否存在连续设定发布；
- 是否一问一答搬运资料；
- 人物语言是否趋同；
- 每句台词是否有当下目的并产生反应；
- 是否符合素人语料的自然来回和金标的信息递进。

### 连续性校验

检查：

- 开场是否执行直接前置选择或结尾事件；
- 人物位置、关系、已知信息、风险和道具状态是否连续；
- 生产卡规定的事件、关系与情绪变化是否在正文发生；
- 结尾是否真实产生后续节点的进入条件；
- 梗概和剧本是否覆盖同一段剧情。

## 七、自动修复

任一校验失败时，只解冻当前集的失败场次，优先执行：

- 删除重复解释和无行动作用的台词；
- 把说明改为劝阻、交换、掩饰、举证、逼问或自保；
- 把长独白拆成有抵抗的多轮来回；
- 保留必要承重句，其余改为普通接话和反应；
- 修正人物、场景、道具与前置状态的不连续；
- 补演选择行为、即时结果或必要转场。

修复后重新运行两类校验。连续两次仍失败时，检查生产卡是否不可执行；生产卡有问题则返回第一轮修订受影响节点及其依赖范围。

只有两类校验均通过，当前集才可冻结并回写真实结尾状态。

## 八、制片格式

校验通过后使用普通 Markdown 逐行排版：

```text
# 第N集《标题》

单集梗概：……

【场一 · 地点 · 日/夜 · 内/外】
出场：人物

△ 可拍摄的动作或环境变化。

人物：台词
```

正式用户呈现不使用代码块、表格、引用块或卡片。动作只写可拍内容，可承载连续动作；场与场之间由前场结果、问题或目标推动。
