# 前后事实连续性检查

本步骤只找事实矛盾，不评价好不好看、不润色台词、不重做结构。

## 检查范围

- 时间：日期、昼夜、先后顺序和时限是否自洽。
- 地点：人物能否合理到达，是否在同一时刻无故出现在互斥地点。
- 知情：人物是否提前知道尚未看见、听见或被告知的事。
- 关系：已经达成或破裂的关系、承诺、称呼和权限是否无故复原。
- 道具：来源、持有人、数量、损坏状态、使用和去向是否连续。
- 事件：已经发生的交易、伤病、损失、死亡、公开信息和不可逆决定是否被后文否认。
- 分支：互斥选择的结果是否被误写成同一路径同时发生；汇合是否保留必要差异。
- 结局：结局所需事实是否在该路径真实发生。

## 证据标准

只有能同时指出“前文事实”和“冲突后文”时才登记问题。以下不算事实矛盾：

- 角色撒谎、误解、忘记或改口，且正文有可识别依据；
- 人物情绪、语气或观点变化；
- 台词不够漂亮、节奏不够强、动作偏多或偏少；
- 没有违背既定事实的省略。

## 修复规则

1. 优先修最早写错的事实；若前文正确而后文漏接，则修后文。
2. 只改造成矛盾的最小句子、动作或场次。
3. 不顺手润色，不新增反转，不改变选择、结局和无关剧情。
4. 修复后重新检查受影响路径。

检查结果只保存在私有缓存。没有矛盾时记录空问题列表；不得向公开剧本添加“校验通过”或解释文字。
