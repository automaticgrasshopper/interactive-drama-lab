# 因果清晰与悬念管理规范

本文件用于悬疑、惊悚、都市传说、犯罪、反转及信息延后揭露题材。目标是让观众始终看得懂人物正在做什么、为什么这样做、做不成会怎样；悬念只保留尚未回答的具体问题，不以角色说明设定或堆叠谜语制造。

本文件只指导内部规划、剧本写作和验收，不新增正式输入、输出或用户可见字段。

## 核心原则

- 戏由人物为了当下具体目标发生的行动与阻力构成，不由解释背景、规则或设定构成。
- 观众优先获得当前人物能看见、听见、碰到、验证和处理的信息。
- 一场戏只处理一块与当下行动直接有关的信息，并在场尾留下一个由本场结果产生的主要问题。
- 悬念是观众明确知道“什么问题还没有答案”，不是让观众不知道人物为什么行动。
- 除最终反转外，每个主要悬念必须在后续通过已建立的行动、证据、人物选择或规则获得明确回答。
- 最终反转只能重新解释前文已经展示的事实、证据或规则，不得临时增加万能能力、关键人物、事故原因或世界规则。

## 一、建立可回看的创作参照

写分集、场次或互动前，先将`游戏企划`、`角色资产`、`场景资产`和`道具资产`收拢为内部创作参照。四项输入缺少任一项时返回上游补齐，不得基于名称、ID 或常识自行补设定。`游戏企划`可能提供游戏题材、时代与地点、玩家身份与视角、核心目标与冲突、基调与情绪、世界观规则与限制和剧情关键节点；角色资产可能提供核心人物与关系方向、角色特征、人物小传、人物关系、声音气质和角色形象描述。

上游信息是已确认的创作边界，不是必须逐项进入剧本的展示清单。分集规划师必须从中筛出能够解释人物当下选择、反应、冲突或代价的部分；暂时不能服务于具体戏剧行动的信息应收拢保留，不强行投放到场次中。

内部创作参照不作为新增正式输出字段，也不直接向用户展示。它不是一次性填满后机械执行的流程，而是写戏时随时回看、并可由有效场次反向补充或修订的两组字典：

- `前史与规则参照`：人物反应、限制、债务、证据和风险从何而来；
- `关系与动机参照`：人物为什么互相推动、阻挡、试探、保护、利用或回避。

### 1. 前史年表与规则参照

按时间先后收录与当前人物选择有关的事件。每个保留节点至少写清：

- 时间或相对顺序；
- 地点与世界规则条件；
- 谁做了什么具体选择；
- 选择的直接后果；
- 谁知道、谁误解、谁隐瞒；
- 遗留到当前剧情的物件、债务、承诺、关系裂缝或风险。

年表不是世界观大事记，也不是剧情待揭晓清单。只保留能够解释人物为何想做、怕做、瞒住、阻止或必须承担某事的旧因。世界观规则也只保留会限制、帮助或迫使人物行动的部分，并落实到具体人物曾如何触发、利用或付出代价。

写场次时，可以用年表核对人物反应是否有来处；当一个有效的戏剧动作、关系变化或证据反过来要求更明确的前因时，可以补写或修订最少必要的年表节点。补写参照不等于立刻在剧本中解释该节点。

### 2. 人物关系与动机参照

对会进入同一冲突的主要人物，按需要记录：

- `表面关系`：亲属、同事、雇佣、师徒、恋人、对手、陌生人等；
- `共同过去`：改变二人关系的一件具体旧事；
- `当前目标`：各自现在想得到、保护、证明、逃避或修复什么；
- `冲突点`：两人当下不能同时得到什么；
- `信息差`：谁知道什么，谁不知道或理解错误什么；
- `关系方向`：本段故事后关系要靠近、决裂、倒置、和解或重新定义什么。

关系参照的用途是为具体动作提供依据：谁会先拦、谁会让步、谁会撒谎、谁会保护、谁会借题施压。不能停留在“关系好 / 关系坏 / 有秘密”的摘要，也不能要求每一项都在戏中说明。

主要人物还应按需要记录起点状态、核心欲望、防御方式、旧因、临界选择和可能的终点变化。人物弧光必须改变其在关键冲突中的选择，并通过可见的行动、关系位置或承担的代价表现；它不是额外附加的背景悲剧或性格标签反转。

### 3. 事实底稿

在创作参照基础上，内部保持一份可随创作修订的事实底稿：

1. `过去事件链`：起因 → 谁采取什么行动 → 造成什么直接后果 → 谁以何种方式掩盖、利用或遗留后果。
2. `现在触发事件`：谁因什么具体事件陷入当前困境，何时必须处理。
3. `主角任务`：主角现在要完成的可拍行动，包括对象、地点、时限或结果。
4. `阻力与人物目的`：谁或什么阻止主角，各自想保护、获得、隐瞒或避免什么。
5. `规则与证据`：关键规则的可见表现、验证方式和后果；支撑关键事实的物证、录音、记录、目击、行动结果或交易。
6. `结局因果`：每个结局由哪项已建立的选择、行动和代价导致。

事实底稿用于保证故事不自相矛盾，不是要求角色一次性说出完整背景。过去信息何时露出，取决于它是否能改变当前人物的行动；过去信息也可长期不展示，只作为人物反应和关系动作的依据。

## 二、从参照中只调用本场所需内容

内部可以知道很多，场次只能调用支撑当前冲突的最少部分。写一场戏前，先确定：

- `注意力对象`：本场让观众持续看住的一个人、物件、行动或地点；不要同场并列投放多个新线索、年份、人物、规则或物件。
- `主要关系`：本场只让一组人物关系承担核心拉扯；其他人物和关系除非改变当前行动，否则延后进入。
- `最少信息`：观众为理解本场行动而必须知道的事实；其余即使内部已知，也不抢先展示。

前史、关系、动机和规则是回看字典，不是本场信息预算。某项信息只有在改变人物此刻要做什么、能否做到或愿意付出什么时，才可进入场内。单场结尾不应同时新增多个待追踪问题。

写一场戏前，再用白话确定以下内容：

- `本场目标`：谁现在要完成什么具体动作；不能写“了解真相”，应写“拿到钥匙进入后台”“说服对方留下”“阻止对方报警”“找到失踪者”。
- `本场阻力`：谁或什么阻止该动作，阻止者为什么这样做。
- `双方动作`：目标方怎样推进；阻力方怎样拖延、拒绝、转移、隐瞒、反击或交换。
- `本场信息`：冲突中只允许观众处理的一块信息；它必须改变人物下一步能做什么。
- `场内变化`：结尾时谁取得、失去或被迫改变了什么。
- `场尾问题`：由本场变化直接产生、下一场必须处理的一个主要问题。

没有目标、阻力、动作和变化的段落，不是完整场次。单纯提问再回答、介绍世界观、复盘过去或解释方案，必须改写为人物在当前行动中争取、隐瞒、举证、拒绝或交换。

## 三、信息必须从人物行为中吐露

背景、规则、身份、关系和过去事件，只能在人物为了当前目的而自然说出时进入戏中。常见动机包括：

- 为了劝阻、说服或逼迫对方；
- 为了自保、掩饰、推责或转移怀疑；
- 为了确认身份、核验线索或识破谎言；
- 为了完成交易、提出条件或争取时间；
- 为了回应眼前证据、异常结果或人物行动。

信息不是角色替观众整理资料，而是人物在压力下泄露、争夺或使用的筹码。

### 禁止说明书式对话

以下情况必须重写：

- 一名角色连续解释过去事故、人物身份、世界规则和解决方案；
- 提问者没有现实目的，只是代替观众索取设定；
- 回答者没有利害关系，却恰好知道并愿意完整说明；
- 台词删去后，人物的行动和关系完全不受影响。

改写时，先补当前行为：谁要走、拿、藏、交、拒绝、逃、留下、报警、签字或进入；再让对方为了阻止或推动该行为，吐露必要的一部分信息。

## 四、一场一块信息，一个主要问题

一场戏可以有环境细节、人物隐瞒和气氛，但只允许观众追踪一个主要问题。该问题必须可用一句普通问句表达，并与人物当下行动直接相关。

合格的问题：

- 失踪的人是否还在这个地点？
- 为什么有人阻止主角进入？
- 这件物品能否证明对方说谎？
- 主角能否在时限前拿到关键物证？
- 对方提出的交换条件能否接受？

不合格的问题：

- 这里究竟藏着什么秘密？
- 这个世界的真相是什么？
- 他为什么如此神秘？

前者能推动动作，后者过大、过空，无法让角色立即处理。

### 问题链

每场结束时，只留下一个由本场结果自然产生的新问题。下一场围绕这个问题展开行动、获得答案或把它具体升级为新的问题。

```text
看到失踪者留下的物件
→ 他是否仍在封闭区域？
→ 找到阻拦者留下的旧记录
→ 阻拦者为什么害怕主角进入？
→ 现场验证记录中的异常
→ 当年到底是谁做出了关键决定？
```

不得在同一场同时要求观众记住过去事故、超自然规则、反派身份、主角身世、救援方案和结局代价。旧问题没有回答前，不得用新的谜语替换它。

## 五、证据、反应与升级

关键戏按以下因果推进：

1. 一方为了当前目标提出要求、判断、拒绝或威胁。
2. 另一方基于自身目的反驳、质疑、隐瞒或反击。
3. 前者拿出当场能看到、听到、触到、核验或执行的证据。
4. 证据迫使人物调整行为，使权力、风险、关系或目标发生变化。
5. 变化形成更具体的行动、交易或选择。

证据可以是物件、记录、人物反常反应、现场结果、可复现的规则后果或被迫承认的事实。抽象异响、谜语、气氛描写和作者旁白不能替代证据。

## 六、规则的展示方式

会影响人物安全、选择或结局的规则必须分三步进入：

1. `触发`：人物在一个具体行为中碰到规则，例如试图开门、回答呼叫、触碰物件、违背约定。
2. `局部验证`：同场或紧接场次出现可见后果，证明当前风险真实存在。
3. `后续兑现`：人物利用、规避或承担该规则，推动关键行动和结局。

规则首次出现时，只说明当前行动需要知道的部分。更深的原理可在后续证据和行动中逐步补全，但不能让观众不知道眼下该做什么、不能做什么及其直接后果。

## 七、台词与动作的关系

台词必须接住前一个动作、事实或台词，并推动对方的反应或下一步行动。每一句重要台词都应能回答：为什么人物偏偏此刻说这句话？说完后迫使谁做什么？

- 普通话茬用于确认、追问、推脱、否认、打断、复述和接住反应。
- 承重信息落在人物需要举证、摊牌、开条件、承认或作出决定的位置。
- 神秘人物可以含混表达，但同场一至三轮内，必须由追问、复述、行动验证或具体风险把当前功能说清。
- 不以“漂亮、阴森、聪明”的台词替代人物目标和可见行动。

## 八、互动选择

互动只能出现于场内已经形成的具体困局。玩家应当立刻知道每个选项：

- 要争取或保护什么；
- 要放弃、承担或冒什么风险；
- 会让眼前人物关系、信息、资源、立场或结局方向发生什么差异。

选择不是“相信 / 不相信”“继续调查 / 放弃调查”这类抽象态度；应是围绕已出现的物件、人物、条件、时限和行动作出取舍。

## 九、逐集戏剧状态与跨集连续性

分集不是彼此独立的短场。完成每集前，内部建立该集的戏剧状态；它用于下游分镜理解连续表演，也用于检查剧情、情绪和互动路径是否形成连续体验。戏剧状态不新增正式输出字段，不向用户展示。

### 每集内部状态

每集记录：

- `戏核`：本集从开头到结尾发生的唯一关键变化；不能写成主题、气氛或单纯发现线索。
- `情感主人`：本集主要承受和推动情绪变化的人；必须在关键场有可见动作或原句台词。
- `当集目标`：主要人物此刻要完成的具体行动；目标来自上集状态、当前触发事件或分支后果。
- `权力变化`：开场谁掌握决定权、信息、空间、资源或关系主动权；结尾如何变化。
- `信息差`：谁知道、隐瞒、误解或试探什么；本集如何验证、利用、缩小或扩大这一差异。
- `前情承接`：本集开场直接承接哪一个前集事件、未完成动作、关系后果、证据、选择或钩子。
- `结尾状态`：本集结束后人物关系、可用证据、风险、目标和情绪处于什么新位置。
- `结尾钩子`：从结尾状态自然长出的一个具体问题、威胁、目标或不得不做的选择。

这些状态必须能从完整剧本、本集冲突、关联资产和互动节点中得到支持。它们用于指导分镜与验收，不替代剧本，也不以标签或分析说明附加到用户正文。

### 情绪脊、戏核与关系变化

情绪脊规定全局体验的方向和反差，戏核规定每集实际发生的变化。二者必须互相支撑：

1. 先按故事体量建立主干情绪脊，确定压制、释放、反噬、翻盘和收尾的主要落点。
2. 再为每集指定一个能推动情绪脊的戏核；戏核必须由人物目标、阻力、行动和结果构成。
3. 情绪不能只靠环境变暗、音乐变急或人物宣称害怕来改变；效价或支配感的变化必须由失去或获得信息、关系、空间、资源、行动权或选择权造成。
4. 每个主要关系在关键戏中至少发生一次可见的位置变化，例如信任转怀疑、保护转控制、服从转反抗、同盟转交易；变化由前史和当下行为推动，不由旁白宣布。
5. 权力变化要落在具体筹码上：谁持有证据、钥匙、话语权、离开权、资源、秘密或他人的信任。下一集保留该筹码变化的后果，不得自动重置。

### 跨集承接

沿每条可达路径，后一集必须从前一集的结尾状态开始，而不是从无关的新谜团或新线索开始。

- 非结局集的结尾钩子，在下一集前段必须被行动回应：验证、追查、利用、部分回答、造成后果或推翻原判断之一。
- 下一集可以提出新的主要问题，但须建立在对上一钩子的回应之后；不得用新谜语覆盖旧问题。
- 上一集获得或失去的证据、承诺、伤害、关系位置、风险和人物目标，必须影响下一集的开场行动、对白、可用选项或权力关系中的至少一项。
- 上一集的情绪落点与下一集开场情绪应构成连续轨迹：可以延续、回落、反转或升级，但必须有剧情原因，不能无故跳变。
- 若删除前一集，后一集仍可以原样开始，说明前情承接不足，应重写前一集结尾或后一集开场。

### 分支与汇合状态

分支不只改变跳转目标，也改变人物所处状态。每条分支至少留下一个可承接差异：信息、关系、风险、资源、承诺、可用物件或权力位置之一。

汇合集必须在剧本、人物目标、对白、可用证据、互动选项或风险中承接至少一项来路差异。不能因为汇合而让人物忘记刚发生的事，或让不同选择进入完全相同的关系和信息状态。

## 十、验收标准

在常规剧本验收前，逐项检查：

1. `游戏企划`、`角色资产`、`场景资产`和`道具资产`已收拢为可回看、可修订的前史与规则参照、关系与动机参照及事实底稿；它们能解释当前冲突，而不是停留在资料摘要或变成必须展示的清单。
2. 事实底稿中的过去事件、当前触发、主角任务、人物目的、规则、证据和结局因果自洽；有效场次如要求补足前因，已回写最少必要参照。
3. 每场只调用一个注意力对象、一组主要关系和理解当前行动所需的最少信息；没有为证明设定完整而堆叠物件、人物、年份、规则或待解问题。
4. 从第一场开始，观众能说清主角现在要做什么、谁在阻止、为什么不立刻放弃。
5. 每场均有目标、阻力、动作、信息、变化和一个场尾主要问题。
6. 每场只处理一块与当前行动直接相关的信息；没有连续说明背景、规则和方案的对话。
7. 每条关键背景信息都能指出人物在何种压力或利益下吐露它。
8. 每条关键规则都经历触发、局部验证和后续兑现。
9. 每个非结尾悬念都能指出其首次位置、解答场次和解答所依赖的既有证据或行动。
