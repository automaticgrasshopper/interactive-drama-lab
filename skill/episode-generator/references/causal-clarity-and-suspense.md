# 因果清晰与悬念管理规范

本文件指导分集规划师在悬疑、惊悚、都市传说、犯罪、反转等题材中建立可理解的前因后果和可回收的悬念。它只规定内部规划、写作与验收方法，不新增正式输入、输出或用户可见字段。

## 总原则

悬念不是把信息藏起来，而是让观众清楚地知道一个具体问题尚未有答案。观众优先看到、听到并能理解人物当下能看到、听到和验证的信息；未知只能留在明确的问题上，不能遮住当前行动的目标、原因、规则、风险或代价。

每一节只保留一个主要悬念。该悬念必须在后续剧情中以先前建立的因果、证据或规则得到解答。只有故事最后的反转悬念可以不在正文内继续解答；它也必须重释或翻转此前已经建立的规则和事实，不能在结尾凭空补充人物、能力、事故或规则。

## 一、先写事实底稿，再写分集

写任何场次、分支或台词前，必须在内部完成一份不可自相矛盾的事实底稿。按实际题材填写：

1. `过去事件链`：起因 → 谁采取什么行动 → 直接后果 → 谁以何种具体方式造成或掩盖后果 → 遗留到现在的后果。
2. `现在触发事件`：谁在何时因为什么具体事件陷入什么危险或困境。
3. `主角任务`：主角为了改变当前局面，必须完成的具体行动、地点、对象和时限。
4. `阻力与对手目标`：谁或什么阻止主角，为什么阻止，失败会发生什么。
5. `规则与证据`：每条关键规则的可见表现、验证方式、代价，以及能支撑关键事实的物证、录音、记录、目击、行动结果或当场交易。
6. `结局因果`：每个结局由哪一个已建立的选择、行动或代价导致；不得只替换结尾台词或情绪。
7. `悬念台账`：每个主要悬念首次出现的位置、观众此刻已知事实、后续负责解答的场次、解答用的证据或行动。

过去事实可以延后揭露，但在内部必须先完整确定。没有事实底稿，或底稿无法解释主角为何行动、角色为何提供信息、规则为何生效时，不得开始写分集。

## 二、观众问题链

每场开头只承接一个观众已经看懂、但尚未解决的主要问题。场内通过行动、对抗和证据给出答案，或把它升级为一个更具体、可行动的新问题；场尾只留下这个新问题作为下一场钩子。

合格链条：

```text
陈放为什么失踪？
→ 他进入封闭站台取事故名册。
→ 为什么不能自行离开？
→ 他回答报站，被系统登记为报站员。
→ 怎样解除登记？
→ 拿到原始证据，到广播台念出被抹去的姓名。
```

不合格链条：

```text
“他已经答过一次了”
→ “你来晚了十年”
→ “名单在控制室下面”
```

后者每句话都貌似神秘，却没有回答上一个自然问题，也没有让主角获得下一步明确行动。

### 每场强制检查

写完每场后，必须能用白话回答：

- 开场时观众已经知道什么？唯一主要问题是什么？
- 谁为了什么提出了什么要求或行动？
- 谁如何阻挡、否认或反击？
- 哪个可见证据、行动结果或具体交易改变了局面？
- 场尾观众新知道了什么？下一场必须处理的唯一问题是什么？

任一项答不出，删除谜面、补足行动或重写场次。

## 三、证据—反应—升级

参照真人剧本中“主张 → 对手反驳 → 更硬证据 → 现实代价 → 被迫选择”的组织方式：

1. 一方提出可被理解的主张、要求或威胁。
2. 另一方以不信、拒绝、追问或反击回应。
3. 前者拿出当场可见、可听、可执行或可验证的证据。
4. 证据改变眼前人物的行动、权力或风险。
5. 在此基础上，把问题升级为更具体的代价、交易或选择。

证据必须解决当前争议，不得用抽象异响、神秘警告、环境怪象或作者旁白代替。背景事实只能在角色为了说服、掩饰、追责、确认身份、完成交易或执行任务时自然出现。

## 四、规则必须先说清、再验证、后使用

每条会影响人物生死、选择或结局的规则，必须遵守：

```text
自然中文说明当前能做什么、不能做什么、做错会怎样
→ 同场或紧接场次用可见结果验证
→ 后续关键行动或结局按此规则兑现
```

例如：

```text
“不要回答报站。你答了，系统会把你的工号写进值班表；写进去的人，即使门打开也走不出去。”
→ 已答应的人无法跨过安全门。
→ 主角必须通过注销或交接值班表救人。
```

禁止只写“别答应”“代价很大”“门会记住你”之类没有机制、对象和后果的警告。

## 五、悬念的数量、展示与回收

- 每一节最多一个主要悬念；它必须能够用一句问句表达。
- 同一场内可以有气氛、未知细节和人物隐瞒，但不得形成第二个需要观众同时追踪的核心问题。
- 悬念出现时，观众必须知道：谁受影响、当下风险是什么、主角为什么要追查或解决。
- 每个非结尾悬念都必须在悬念台账指定的后续场次，以已出现的线索、证据、角色行为或规则获得明确解答。
- 解答后可以生成下一个问题，但不能把旧问题悄悄换成另一个谜语。
- 最终反转可不在后续解答，但只能重新解释先前已呈现的事实、规则或证据；不得依赖此前未出现的万能能力、隐藏人物、突然事故或新增规则。

## 六、谜语和修辞的边界

神秘人物可以说含混话，都市传说可以保留超自然来源，但不能代替功能信息。任何含混、象征、谜语或修辞性台词，必须在同场下一至三轮内由另一角色完成至少一种处理：

- 直接追问其具体意思；
- 用白话复述当前规则和风险；
- 用行动验证其中一部分；
- 明确它要求主角立刻做什么。

如果这句话不承担可被解释和验证的剧情功能，删除它。

## 七、交付前专项验收

在常规剧本验收之前，逐项通过：

1. 事实底稿完整，过去事件、当前触发、主角任务、阻力、规则、证据和结局因果互不矛盾。
2. 从第一场起，观众能说清主角此刻为什么行动、要做什么、不做会怎样。
3. 每场只有一个主要悬念，并能指出其问句、解答场次和解答证据。
4. 所有非结尾悬念已经明确解答；没有被新谜语偷换或遗忘。
5. 每条关键规则均已说明、验证并在后续兑现；没有结尾临时补规则。
6. 每条关键背景信息都由当前冲突中的人物行动、证据或交易带出。
7. 每个互动选择都回应已形成的具体困局，玩家立刻知道每项在争取什么、会失去什么。
8. 最终反转如存在，只重释既有事实与规则，回看前文能够成立。

任一项失败，先回到事实底稿和问题链返工，不允许靠添加氛围台词、旁白或解释段落掩盖因果漏洞。
