# 情绪脊状态拓扑

本卡用于以情绪脊规划并冻结可执行互动拓扑，统一状态、条件、效果、路径枚举和结构审计。

## 一、两个最小单元

### 拓扑最小单元

```text
玩家动作 → 状态写入 → 独立结果
```

- 玩家动作必须能在当前现场立即执行。
- 状态写入是行动造成的事实变化，不是作者评价。
- 独立结果先演出新事实，再决定是否汇合。

### 写作最小单元

```text
触发 → 判断 → 欲望 → 行动 → 阻力 → 调整 → 即时后果 → 下一压力
```

一次只推进相邻一拍。拓扑节点是一集，一集可以包含若干连续因果拍。

## 二、故事运行基础

先冻结：

- 故事核心、主题、题材、世界规则、目标时长。
- 正式角色及其动机、知情、能力和声音。
- 正式场景与道具。
- 结局方向和必保事件。
- 状态注册表。

状态只在满足以下条件时注册：

1. 玩家行动能改变它；
2. 后续条件、人物反应、资源权限或结局会读取它。

可用类型：

- `flag`：是否发生，如证人已转移。
- `counter`：可累积次数或额度，如证据完整度。
- `relationship`：关系状态，如记者信任。
- `item`：物件持有或状态，如录音机由谁保管。
- `evidence`：发现、取得、验证、合法接手、损坏等生命周期。
- `permission`：进入、调用、公开、取证或行动权限。
- `risk`：曝光、追捕、受伤、失联等已被行动改变的风险。

不因结构支持数值就强行量化。能用清楚的自然状态表达，就不用伪精确分数。

## 三、情绪脊逻辑

内部术语备忘：`V（Valence）`表示感受的正负方向，`A（Arousal）`表示情绪的平静或激烈程度，`D（Dominance）`表示人物对局面的被动或掌控程度。

每个阶段记录：

1. 人物幻想：他以为采取什么行动就能得到什么。
2. 现实风险：这个行动实际携带什么代价。
3. 现实落点：代价何时以具体事件落地。
4. 控制权变化：谁获得或失去行动权、解释权、资源或关系主动。
5. 下一催化：什么新压力迫使人物继续行动。

全剧情绪脊：

- **起**：建立缺失、压制、装置和第一份可兑现幻想。
- **承**：玩家行动产生可见收益或关系靠近，同时写入由收益带来的风险。
- **转**：此前写入的风险落地，使判断、关系或控制权反号。
- **合**：累计状态与最后行动共同决定人物怎样夺回、交出或重新定义控制权。

每条主要路径至少包含一次由玩家先前行动促成的有效释放，以及一次由同一行动携带风险造成的反噬。

## 四、节点契约

每个私有拓扑节点至少记录：

```text
节点ID
节点类型：start | normal | branch | result | merge | ending
情绪位置：起 | 承 | 转 | 合
现场触发
人物当下欲望
现实阻力
采取行动
即时事实
控制权变化
状态读取
状态写入
下一催化
后续节点
```

只有人物采取具体行动、遇到阻力或判断，并产生新事实、关系、资源、风险、选择或行动方向时，才独立成集。

## 五、选择契约

一处选择必须同时通过：

1. **行动门**：至少两个合理、互斥、立即可执行的动作。
2. **情绪门**：动作在控制权、关系、价值、代价或风险上通向不同方向。
3. **状态门**：每个动作写入不同状态，或进入不同即时事实。

每个选项记录：

```text
选项文字：动词＋明确对象
目标结果节点
可选条件：只能读取已写入状态
状态效果：set | add | sub，或明确的自然状态迁移
选择重量：light | heavy | critical（只用于判断影响范围，不作为配额）
```

每个选项先进入自己的结果节点。不同选项直接指向同一节点且没有不同效果，属于假分支。

## 六、汇合契约

- 汇合只统一下一共同事件。
- 共同节点只能使用所有来路都成立的事实，或在本场重新取得的事实。
- 未解决的信任、物件、证据、风险、知情与权限继续存在。
- 条件分支不能读取从未写入的状态。
- 不可通过旁白宣布差异消失；必须由行动解决或被后续结局读取。

## 七、结局契约

- 结局条件必须读取玩家此前造成的累计状态，并结合终局行动。
- 每个正式结局在所得、失去、关系、控制权或价值判断上实质不同。
- 失败结局由玩家当前或此前行动造成，不靠突然事故。
- 每个结局必须有至少一条真实状态路径可达。

## 八、结构审计

冻结前检查：

- 唯一入口、编号连续、目标存在。
- 非结局无死路，结局无后继。
- 所有节点从入口可达，每条真实路径能到结局。
- 条件读取的状态存在且此前有写入。
- 声明状态至少被写入或读取；纯装饰状态删除。
- 每个分支目标或效果不同，不存在假分支。
- 选择先进入独立结果节点。
- 汇合不使用路线私有事实。
- 结局类型和价值结果有差异。
- 连续直链若长期没有控制权变化，应合并节点或加入真正事件，不为互动数量强行加选择。
