# 阶段依赖与内容追溯契约

本规范把分集生产变成单向、带内容指纹的依赖链。reference 凭证只证明说明已经装载；阶段封印另行证明当前下游确实建立在未变化的上游产物上。二者缺一不可。

## 固定链路

严格按以下顺序执行：

```text
upstream
→ emotional-spine
→ causal-graph
→ topology
→ production-cards
→ drafts
→ reviews
→ state-writeback
→ final
```

使用：

```text
python3 scripts/seal_pipeline_stage.py {canvas-root} --cache-root {cache-root} --stage {stage} --mode seal
python3 scripts/seal_pipeline_stage.py {canvas-root} --cache-root {cache-root} --stage {stage} --mode verify
python3 scripts/seal_pipeline_stage.py {canvas-root} --cache-root {cache-root} --mode status
```

封印包含当前阶段选定栏目、当前 reference 凭证和上一阶段完整封印的 SHA-256。任何上游文字、结构、生产卡或正文变化都会使当前阶段及全部下游自动过期。不得复制旧凭证、修改 JSON、跳过阶段或以人工 PASS 替代封印。

## 中断恢复

每次新回合或用户点击继续后，先运行`--mode status`。脚本返回最后一个仍有效阶段和必须继续的下一阶段：

- 已封印且仍有效的阶段不得重做。
- 已写入但尚未封印的下一阶段视为可恢复草稿；先校验完整性，完整则封印，不完整则只重做该阶段。
- 任一已封印上游发生变化时，从最早失效阶段重算，不能沿用其下游。
- reference 或 Skill 版本未改变的普通中断不会使封印失效。
- 最终组三个公开文件先写入私有 staging，再整体替换公开文件；只有替换完成并封印 final 后才允许发送完成消息。中断后重新运行 finalizer 会从冻结私有内容重建同一组三个文件。

## 情绪脊产物

`emotional-spine.md` 的每个事件使用：

```text
## ES-001｜事件名
- 阶段功能：开场钩子/首次释放/中段反噬/高潮解法/其它实际功能
- 当前欲望：人物眼前想得到什么
- 当前恐惧：人物眼前最怕失去什么
- 压力来源：正在逼迫人物行动的具体事实
- 造成行动：人物因此实际做什么
- 不可逆结果：行动造成什么无法原样撤销的损失、承诺或关系变化
- 下一催化：这个结果怎样迫使下一行动发生
- 起点VAD：(V,A,D)
- 落点VAD：(V,A,D)
- 情绪位移：欧氏距离，保留两位小数
- 强度处理：原始通过/放大后重算
- 放大前位移：仅放大后重算时填写
- 事件升级：仅放大后重算时说明坐标放大后同步增强的具体行动、损失和不可逆结果
```

至少覆盖开场钩子、首次释放、中段反噬和高潮解法。最大位移不得低于 1.10，平均位移不得低于 0.70。强度不足时放大坐标，同时重算压力、行动、损失和下一催化；只改数字不能封印。

## 因果图产物

`causal-graph.md` 的每个事件使用：

```text
## CG-001｜事件名
- 情绪事件：ES-001
- 原因：来自上一个已发生结果的具体原因
- 人物行动：人物主动采取的动作
- 阻力：人物行动遇到的实际阻力
- 不可逆结果：行动留下的不可撤销结果
- 下一事件：CG-002, CG-003/结局
```

每个情绪事件至少进入一个因果事件。因果图必须无循环、无未知引用；不能用主题、情绪标签或“剧情需要”充当原因。

## 拓扑追溯

每个 `topology.md` 节点在原字段之外增加：

```text
- 情绪事件：ES-001
- 因果事件：CG-001
```

选择节点对每条出口增加：

```text
- 选择后果：episode-003｜ES-002｜CG-003｜不可逆结果的具体说明
```

合流节点存在多个直接前置时增加：

```text
- 合流保留差异：episode-003=仍保留的关系/信息/风险；episode-004=仍保留的关系/信息/风险
```

每条选择边必须有不同的可追溯后果。合流可以共享事件，不得清除来路造成的状态差。

## 生产卡继承

每个逐集文件的 `生产卡` 必须首先包含：

```text
- 拓扑节点：episode-001
- 情绪事件：ES-001
- 因果事件：CG-001
```

引用集合必须与该拓扑节点完全一致。生产卡可以把因果事件展开成场面，不得更换核心事件、另造反转或绕开不可逆结果。

## 公开写入

拓扑阶段只允许在私有缓存生成预览，不写公开 Canvas。`episode-synopsis.md`、`episode-flowchart.svg` 和 `episode-script.md` 只能在 `state-writeback` 已封印后由 `finalize_episode_artifacts.py` 组装；组装后封印 `final`。公开校验必须验证 `final` 封印与三个当前文件逐字匹配。

Agent 不得直接写、复制或手工修补三个公开文件。公开内容需要修改时，修改最早受影响的私有阶段，重新封印它及全部下游，再由 finalizer 重建。
