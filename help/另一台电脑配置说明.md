## 一、装 git 和 gh（GitHub 命令行）

### macOS
```bash
# 如果没有 Homebrew，先装（官网命令），有就跳过
brew install gh          # gh 会带上 git；git 一般系统自带
```

### Windows
- 装 Git：https://git-scm.com/download/win （一路默认即可）
- 装 gh：https://cli.github.com/ 下载安装，或用 winget：
```powershell
winget install --id GitHub.cli
```

验证（两个系统通用，装完新开一个终端）：
```bash
git --version
gh --version
```

```bash
git config --global user.name  "automaticgrasshopper"
```

## 三、登录授权 GitHub
```bash
gh auth login
```
按提示选：**GitHub.com → HTTPS → Login with a web browser**。
终端会给一个 **一次性验证码**（形如 `XXXX-XXXX`），然后打开 https://github.com/login/device
输入验证码 → 点 **Authorize** → 选账号 `automaticgrasshopper`。

让 git 用 gh 的登录状态（配一次，以后推拉免密）：
```bash
gh auth setup-git
```

验证：
```bash
gh auth status        # 显示 Logged in to github.com account automaticgrasshopper 即成功
```

---

## 四、把两个仓库 clone 下来
先 `cd` 到你想放代码的目录，再：
```bash
gh repo clone automaticgrasshopper/interactive-drama-lab
gh repo clone automaticgrasshopper/game-index
```

## 五、日常怎么用（两台电脑同步的规矩）

- **开工前先拉最新**（防止覆盖另一台的改动）：
  ```bash
  cd interactive-drama-lab
  git pull
  ```
- **改完要保存到云端**：让 Codex 帮你提交，或手动：
  ```bash
  git add .
  git commit -m "说明这次改了啥"
  git push
  ```
- 对 Codex 说 **“提交互动相关 / 故事节奏相关”**，它会先核对工作区和远端状态，再把这套文件提交到 `interactive-drama-lab` 并推送。

**铁律**：换电脑工作，永远 **先 `git pull` 再动手**；离开前 **`git push`**。两头都守这条，就不会丢、不会冲突。

### 两台电脑同步（一句话）
clone 到两台电脑，改完 `push`，另一台 `pull`。目录永远不丢、带版本历史。

## 六、这是公司电脑 —— 想解除授权时
不想让这台电脑再连你的 GitHub：
```bash
gh auth logout
```
要彻底撤销，再去网页删掉授权：
https://github.com/settings/connections/applications → 找到 **GitHub CLI** → Revoke。
