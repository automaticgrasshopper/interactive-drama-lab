# 逐集记忆包与隔离观众复核

每集初稿完成后读取。目标是让不知道作者计划的观众只凭已经看过的剧情和当前正文判断是否看懂，不替场面事实层和人物交流层重复审稿，也不让入口硬状态泄露正文尚未交代的答案。

## 一、两种输入包

### 写作包

写当前集时只携带：

- 当前生产卡与场级施工图；
- 直接前置真实结尾和直接后续进入条件；
- 当前路线相关人物、关系、知情、证据、道具与未回收钩子；
- 已冻结分集的观众摘要；
- 当前集相关资产。

### 隔离观众包

隔离观众复核时只携带：

- 当前路径中已冻结分集的观众摘要；
- 当前集完整正文；
- 本文件的观众六问。

不得携带入口硬状态、语义触发登记、生产卡、作者意图、人物秘密说明、后续结局、目标情绪、预期答案、字数目标或写作时的解释。复核应在独立、无写作历史的上下文中执行；无法获得独立上下文时，必须重新只读取隔离观众包，并在记录中标注`隔离方式：最小上下文复检`，不得声称是真正独立读者。

## 二、观众摘要

每集冻结后生成一条六十至一百个汉字的摘要，只写观众已经看见的内容：

```text
E001｜结果；关系变化；新增信息；关键物件状态；具体未决问题。
```

摘要不写作者计划、未来答案、路线评价和主题解释。当前节点只加载其祖先节点；互斥路线不得混成共同前情。

汇合节点的摘要分为：

```text
共同事实：所有有效来路都成立的事实。
路线差异：各来路仍不同、但不妨碍公共开场的状态。
```

公共正文只能直接使用共同事实。需要使用路线差异中的关键物件或知情时，必须先在公共场面重新取得，或返回拓扑处理。

## 三、入口硬状态只供场面事实层使用

它不是剧情摘要，只记录当前正文不可违反的事实，控制在三百至六百字：

```text
人物位置与行动能力：
关系与当前目标：
已知与未知：
证据、道具的持有人和地点：
明确不存在或已经失去：
本集允许使用的权限与功能角色：
直接后续所需入口：
```

初稿完成后，场面事实层先核对正文使用的关键人物、证据、道具、权限和知情是否能在硬状态或本集现场取得过程中找到来源。找不到即 FAIL，不进入隔离观众复核。入口硬状态不得传给隔离观众；观众需要知道的事实必须已经出现在路径内观众摘要或当前正文中。

## 四、隔离观众的阅读边界

动作可拍和对白可说分别归场面事实层与人物交流层，不在此重复判定。隔离观众若遇到抽象动作、报告式对白或主题总结，只记录它具体妨碍了哪一项理解，不另建门、不提供改写稿。

## 五、观众六问

把自己当作已经看过路径内前情、但不知道作者计划的普通观众，逐项回答并定位正文场次：

1. 能否用一句话说清本集发生了什么？
2. 当前正文首次出现的人物是谁、为什么来、与现场人物是什么关系；没有新人物时明确回答`无`？
3. 主要事件在哪里发生、谁先感知、人物第一反应是什么，顺序是否仅凭正文成立？
4. 核心关系若被触发，观众从哪一个说话顺序、身体反应或行动优先级看出来；未触发时明确回答`无`？
5. 重要对白正在回应哪个眼前的人、动作或物件，是否存在主要用于发布作者信息或总结主题的段落？
6. 可见结果是什么，结尾留下的下一行动或具体问题是什么？

出现以下任一情况直接 FAIL：

- 必须依赖生产卡或作者解释才能回答；
- 重大结果由一句总结、裁决、认罪、和解或时间跳跃完成；
- 一集塞入三个以上彼此独立的重大结果；
- 人物、证据、道具、权限或知情只能依赖未提供给观众的硬状态才能成立；
- 人物只处理事情，没有对重大得失作出反应；
- 台词主要用于轮流发布资料，而不是回应眼前的人与事。

## 六、判决与单次修复

固定输出：

```text
VERDICT: PASS/FAIL
隔离方式：独立冷读/最小上下文复检
正文 SHA-256：
一句话复述：
失败项：无/第X问
正文定位：无/具体场次与原句或动作
观众卡点：无/为什么看不懂或不相信
返工边界：无/只说明应补哪一步，不给成稿
```

FAIL 后只返回被定位场次和卡点，由生成方按职责归入场面事实层或人物交流层修复。任何正文修改都会使旧 SHA-256 与全部语义 PASS 失效；修改动作、场次或事实时从场面事实层重跑，纯对白修改时重跑人物交流层和隔离观众层。一次修复仍失败时返回生产卡；不得继续补动作、补解释台词或放宽篇幅门槛。PASS 后才写观众摘要并冻结本集。
