# 逐集独立复检

本 reference 只用于正文与整场人话复写完成后的逐集复检，不参与拓扑和初稿生成。

## 输入边界

只读取当前集最终正文、直接前置的真实结果、当前入口／出口状态、直接后续入口与正式资产。不要读取初稿评价、作者自检结论或上一轮“通过”判断。复检对象必须绑定当前正文 SHA-256；正文有一字变化，旧结论即失效。

## 七项完整覆盖

逐场通读，不抽样，并明确覆盖以下七项：

1. **事实来源与知情**：人物、地点、权限、证据、装置与物件来源成立；人物只使用此刻已经知道的信息。
2. **首次出现与必要交代**：按当前观看路径判断人物、组织、地点、装置、能力和关键名词是否第一次出现。首次出现时，观众必须能从当场动作、称呼、证据或自然反应认出“这是谁／是什么、与眼前事情有什么关系、此刻为何需要知道”；姓名也须有可懂来源。只交代理解当前行动所需的最小信息，不写百科介绍。
3. **因果相邻与可见后果**：事件发生后，人物先感知并作出符合欲望、压力和能力的反应，再行动、受阻、调整并形成可见结果；不得跳过必要接触、移动、失败尝试或代价。
4. **话茬与现场目的**：问题、命令、请求和指责得到回答、拒绝或可识别的回避；每句话回应眼前的人事，不替作者发布剧情和主题。
5. **口语组织与反过度压缩**：检查连续普通关系话轮是否只剩最短语义骨架，是否缺少有作用的对象、承接、态度或关系指向。危急口令、无线电协作、程序确认，以及被相邻动作或话轮接住的纯事实短答可以短，不得机械补语气词。
6. **普通话表达与叙述可读**：把台词和非台词描述分别按自然普通话顺读一遍。台词用日常语序，避免生硬倒装、名词堆叠、字幕式压缩和作者金句；描述写清谁做什么、对象与位置怎样变化、前后为何相连，避免抽象判断代替画面。古装、科幻等可保留必要词汇，但句法仍须直接可懂。本项必须分别登记一处台词证据和一处描述证据。
7. **结尾画面与下一入口**：本集落在可拍的动作、位置变化、信息暴露、物件变化或迫近压力上；不用主题总结代替结果，并能实际进入冻结拓扑的直接后续。

## 判定与返修

- 复检只判不改。每个问题必须写明所属层、可定位位置和具体原因；正常内容不逐句报通过。
- 七项检查缺一项即不通过；没有实际问题时，问题列表必须为空。
- 不得把个人风格偏好、句子短、留白或人物不够讨喜单独判为问题。
- 未通过时，由写作层只修登记的问题；不得顺手改拓扑、选择、状态效果、结局或无关场次。
- 返修后必须对新正文重新执行本 reference。只有七项全部覆盖、问题为空且记录绑定当前正文 SHA-256，当前集才可冻结、组装或回写状态。
