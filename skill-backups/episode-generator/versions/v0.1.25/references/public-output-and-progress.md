# 对外输出与进度封装协议

本协议是 `episode-generator` 的唯一公开边界。制作数据可以完整保存在 Canvas 外私有缓存中，但不得通过 Canvas、对话进度、阶段总结、完成消息、工具摘要或下游展示字段泄露。

## 一、公开成果白名单

本 Skill 只允许在共享 Canvas 根目录直接创建以下两个一级文件：

- `episode-flowchart.svg`：由冻结拓扑生成的完整分集流程图。
- `episode-script.md`：由全部已冻结逐集定稿原样组装的完整剧本。

Canvas 中其它模块已有的一级文件保持不变，不属于本 Skill 的产物白名单。分集大纲、节点梗概、选项表、Mermaid 源码和九字段组装数据均不单独公开；它们不得形成项目子目录、第三个分集公开文件、阶段报告或附录。

## 二、绝对私有的数据

以下内容统一封装为私有制作数据，永不对外展示、引用、链接、列目录或复述：

- `.episode-generator-cache/` 的路径、文件名和全部内容；
- reference 阶段清单、装载 bundle、文件哈希、凭证和 `.reference-receipts/` 的全部内容；
- 原始输入副本、上游阅读包、制作参考、事实基线、拓扑源、Mermaid 源码、生产卡和滚动窗口；
- 主干情绪脊、PAD/VAD、力度阈值、实现概率、互动预算、分支审计和路径统计；
- 初稿、修订稿、未冻结正文、人物/道具/钩子状态、正文指纹和修复记录；
- 可见字符数、动作段数、PASS/FAIL/PENDING、校验证据、失败原因、修复次数和未解决问题；
- 下游九字段的内部组装过程、参数对象和临时交接数据。

“私有”不仅表示不写入 Canvas，也表示不在对话中说明其值、状态、路径、文件名或判断依据。不得用“为了透明”或“必须说明”为理由披露。

## 三、可见进度白名单

默认不发送中间进度。只有更高层运行规则明确要求阶段更新或心跳时，才从下列句式中选择最贴近当前阶段的一句，单独发送，不增加标题、数量统计、解释、结果或下一步：

- `正在整理上游资料`
- `正在生成分集流程图`
- `第 {n}/{total} 集正在写作`
- `正在检查人物与道具连续性`
- `第 {n} 集有逻辑问题，正在定点修复`
- `正在组装最终剧本`

其中 `{n}` 和 `{total}` 只能填写集号与总集数。不得出现分集标题、字数、动作段数、校验名称、通过/失败结论、内部文件、缓存状态、推理过程或修复原因。

## 四、禁止以未完成状态结束

流程图、完整剧本或复核尚未完成时，继续执行、定点修复并从未冻结节点恢复，不得对用户发送草案盘点、缺口清单、机械检查结果、“下一步”计划或停止理由。不得把内部未完成状态包装成阶段交付。

只有必需输入确实缺失、主线级冲突无法唯一解释、权限不足或持久化工具不可恢复时，才请求最小必要信息。提问只说明用户需要补充或授权的对象，不披露私有缓存、内部判断链、失败记录或中间产物。

## 五、完成消息

只有流程图覆盖全部节点与边、全部分集正文冻结、最终校验通过且两个公开文件已经写入时，才能发送完成消息。完成消息只包含简短完成状态，以及 `episode-flowchart.svg` 和 `episode-script.md` 两个入口；不报告校验范围、指标、内部过程、分集大纲、缓存或下游参数。
