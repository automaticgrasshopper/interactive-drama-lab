# 剧本执行与逐集校验规范

根据冻结生产卡写完整剧本时读取；不参与第一轮拓扑设计。

## 一、规则优先级

发生冲突时按以下顺序处理：

```text
事实与人物反应成立
> 场景完整自然
> 生产卡结果与边界得到执行
> 人物说人话
> 制片格式正确
```

低优先级不得破坏高优先级。生产卡冻结的是入口事实、核心结果、路径状态和出口，不冻结每一个动作、反应与句子。结构、前史、权限或人物关系有问题时返回生产卡，不用台词或旁白补洞。

## 二、先写连续戏

不要直接对着动作与台词模板逐行填充。根据场面本身选择事件驱动或对抗驱动的连续因果。

事件驱动场面：

```text
正常状态
→ 事件发生并被人物感知
→ 人物作出自然反应
→ 旁人按自己所知解释或处置
→ 产生现实后果
→ 人物采取下一步行动
```

对抗驱动场面只在双方目标真实相冲时使用：

```text
人物为当前目标采取行动
→ 对方基于自身目标阻挡或回应
→ 动作和台词迫使下一次反应
→ 信息、关系、权力、目标或风险发生变化
→ 本场结果推动下一场
```

一场戏只要完整演出事件、反应、结果，并改变后续行动，就完成了戏剧任务。不要求每个角色都有独立目标，不强制冲突、关系变化、权力翻转或选择。只有一个动作和一句反应且没有结果时，应与相邻内容合并或继续展开。

新人物首次出现时自然交代出场动作、身份锚和来意。场景首次使用时说明人物为何进入；道具首次出现时交代原位置、发现者或取得过程。

## 三、关键情节与题材辨识

承担互动、反转、高潮或分集落点的关键情节必须同时具备：

1. 可见、可信、可拍摄的具体事件；
2. 只在当前题材和既有规则下成立的反差物；
3. 由人物行动造成的规则内升级；
4. 能推动下一场或下一集的结果、问题或选择。

关键反转必须来自“既有铺陈触发行动，行动造成反差结果”的连续因果。不得用无关突发事故、临时新增规则或新人物替代反转。

第一集应先建立主角的正常处境和做事方式，再让异常具体发生；让观众看懂主角为何在场、为何反应和接下来准备做什么。主要关系只需在它自然参与事件时登场。

## 四、中文对白

具体对白以 `chinese-dialogue-craft.md` 为准。写作时执行：

- 普通搭话、确认、追问、拒绝、回避、复述、迟疑和反应占多数；
- 承重句只放在举证、揭露、关系变化、规则说明、条件和决定处，不超过一场台词的三分之一；
- 连续三句都在发布背景、规则、秘密或结论时，拆回可见动作、普通反应或真正存在目标阻力的来回；
- 每句重要台词都回应前一个动作、台词或眼前事件，并推动当场处置或下一行动；
- 不同人物依据身份、关系、欲望和声音气质形成不同说话方式；
- 悬疑、古装、危险关系和奇幻题材不等于短句、机锋、谜语或海报句堆叠；
- 功能信息必须一遍听懂，悬念只保留具体问题的答案。

## 五、真人样例对照

每集初稿完成后先读取：

- `chinese-dialogue-craft.md` 中与当前题材或关系最接近的素人短剧片段；

再按场面类型有条件读取：

- 只有外部问题的解决方式会反噬人物关系时，读取《权势解围与关系反噬》；
- 只有谈判、审讯、威胁、举证或条件逐级加码时，读取 `gold-sample-episode.md` 中《刘熙的条件》；
- 发现、日常连接、独处反应和纯事件驱动场面，不为贴合样例改造成对抗。

校验只使用以上语料，禁止临时生成 AI 示例句。只比较方法，不复制台词和情节。

对照素人语料检查：

- 人物是否围绕眼前具体事情说话；
- 是否存在来意、拒绝、追问、劝说、改口和反应；
- 熟人、陌生人、上下级和对手的口气是否不同；
- 是否像真实中文交流，而不是轮流吐露资料。

对照《权势解围与关系反噬》检查：

- 人物是否因现实利益接受或拒绝帮助；
- 外部冲突的解决办法是否反过来改变关系；
- 前段表达的价值观是否被后段人物行动实际检验；
- 场景结束后是否留下必须承接的关系后果。

对照《刘熙的条件》检查：

- 每个人当下目标是否明确；
- 对方抵挡后才亮出更硬证据，而非一次倒完背景；
- 证据是否改变权力和行为；
- 互动是否从具体条件与代价中自然产生。

## 六、逐集双校验

每集写完后先保存初稿，再分别执行两类校验。

### 中文对白校验

检查：

- 承重句是否过量；
- 是否存在连续设定发布；
- 是否一问一答搬运资料；
- 人物语言是否趋同；
- 每句台词是否有当下目的并产生反应；
- 是否符合素人语料的自然来回；若本场属于举证或条件升级，再检查《刘熙的条件》的信息递进。

### 因果与连续性校验

检查：

- 开场是否执行直接前置选择或结尾事件；
- 人物为何在场，是否拥有相应进入、查看、触碰或处置权限；
- 事件是否先发生并被感知，再产生人物反应和下一步行动；
- 物件的来源、位置、移动路径和当前持有是否清楚；
- 人物位置、关系、已知信息、风险和道具状态是否连续；
- 生产卡规定的核心事件、路径状态、定性体验功能和结果是否由实际事件完成；
- 结尾是否真实产生后续节点的进入条件；
- 梗概和剧本是否覆盖同一段剧情。

## 七、自动修复

任一校验失败时，只解冻当前集的失败场次，优先执行：

- 删除重复解释和无行动作用的台词；
- 把说明改为可见事件、普通反应，或确实存在的劝阻、交换、掩饰、举证、逼问和自保；
- 把长独白拆成动作与短反应；只有真实对抗场面才拆成有抵抗的多轮来回；
- 保留必要承重句，其余改为普通接话和反应；
- 修正人物、场景、道具与前置状态的不连续；
- 删除为满足模板而添加、却不改变结果的虚假冲突和装饰性角色功能；
- 补演选择行为、即时结果或必要转场。

若失败来自人物权限、关键证据来源、世界规则或核心因果，不得用新增对白修补，直接返回生产卡。修复后重新运行两类校验。连续两次仍失败时，检查生产卡是否不可执行；生产卡有问题则返回第一轮修订受影响节点及其依赖范围。

只有两类校验均通过，当前集才可冻结并回写真实结尾状态。

## 八、制片格式

校验通过后使用普通 Markdown 逐行排版：

```text
# 第N集《标题》

单集梗概：本集梗概。

【场一 · 地点 · 日/夜 · 内/外】
出场：人物

△ 可拍摄的动作或环境变化。

人物：台词
```

Canvas 正文不使用代码块、表格、引用块或卡片。动作只写可拍内容，可承载连续动作；场与场之间由前场结果、问题或目标推动。
