# 幻想空间、恋爱角色与题材催化补丁

本补丁只在情绪脊与拓扑冻结前工作，不改变上游事实、九字段、公开文件、逐集正文格式或既有拓扑规则。上游明确事实、人物动机和现实因果始终优先。以下记录只留在私有规划中，不向玩家展示，也不为填表强造事件。

## 三维目标与让位关系

同时追踪：

- `关系目标`：主角与核心恋爱或关系人物想靠近、远离、保护、取得信任或改变什么。
- `任务目标`：主角在事业、求生、查案、竞技、成长等当前题材中要完成什么。
- `主角情绪`：关系事件与任务事件叠加后的即时结果，不把情绪另写成一条独立剧情。

恋爱及恋爱融合题材提高关系目标权重，非恋爱题材提高任务目标权重；这是连续让位，不要求每段均分。两项目标要求不同动作时进入候选岔点扫描，但只有动作可执行、互斥且产生真实状态差时才落图。

## 幻想、反讽与认同账

起、承、转、合中每次激励事件真正撑开玩家期待时，内部登记：激励事件、关系幻想、任务幻想、主角情绪、现实实现概率 `p`、观众已知而主角未知的风险、现实落点、下一催化剂。没有形成对应幻想时写`无`，不得补事件凑齐三维。

`p∈[0,1]`只表示故事现实中的可达性，不表示渴望强度；使用低、中、高或粗区间即可，不做伪精确计算。幻想与现实的落差必须推动人物下一步行动。

执行认同开关：

1. `负面可剥离`：受辱、作恶、背叛、放弃关系或不可逆损失发生前，如玩家存在另一合理行动，不得由编剧直接替玩家完成。
2. `正面可认领`：翻盘、救人、关系靠近和重大成果优先由玩家此前选择促成；纯自动发生不能承担核心爽点。
3. `风险须兑现`：每个主要幻想至少登记一条反讽风险，并在后续触发、反用或明确解除；不得只登记不回收。

## 恋爱题材的关系角色节奏

仅在上游明确为恋爱或恋爱融合产品时启用，并沿用上游已确认的性别、取向和关系边界，不擅自增加可攻略角色。

- 约六小时体量容纳二至五名主要恋爱角色；约一小时体量建议二至三名，其中可有一名功能性关系角色，一小时最多三名。更短体量按实际容量下调；数量是上限，不是必须填满的配额。
- 不在开场同屏陈列多名角色供玩家挑选。错峰登场，每名角色先用独立事件建立欲望、秘密、代价和与主角的具体关系，再进入集中选择。
- 集中选择是前期关系投入的回收节点。选择后必须产生独占信息、关系动作、后续状态或连续差异路线，不能选完立即归零。
- 男性向可用更直接的关心、关系成长和合规的非露骨亲密吸引兑现；女性向优先用私密秘密、独有记忆、被理解和后续回环兑现。只在上游明确受众时采用，不凭角色性别推断玩家期待。

## 关键节点的题材透镜

互动、首次释放、反转、高潮、结局和分集落点依次检查：

1. `具体事件`：人物在具体地点做一件可信、可拍且产生结果的事。
2. `题材反差物`：改变局面的因素依赖当前题材或项目独有规则；换题材仍完全成立则不够独有。
3. `题材内升级`：结果沿同一世界规则继续升级，不用道歉、退款、巧合、突然来电或普通事故替代题材兑现。
4. `催化钩子`：收口直接形成下一段行动口；优先使用福祸未知、帮害难辨但当前事实可理解的双义钩子。

普通移动、程序处理和关系过场可以作为场内连接，不必各自制造反差；但不能独占关键节点或成为分集最终落点。上述四项任一不成立，返回该节点事件设计，不靠新增台词或无来源设定补洞。

## 冻结前验收

- 关系与任务权重符合题材，主角情绪由具体结果读出。
- 主要幻想具有可达性、反讽风险、现实落点和下一催化剂。
- 负面关键行动没有替玩家决定，核心爽点能由玩家选择认领。
- 恋爱角色数量、错峰登场、集中选择与选择后兑现符合体量。
- 关键节点具有具体事件、题材反差物、规则内升级和催化钩子。

失败时只返回对应情绪事件、关系节奏或节点设计；不得借补丁改写不相关拓扑。
