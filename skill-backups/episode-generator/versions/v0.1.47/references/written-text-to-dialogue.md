# 画内文字信息转台词

只在当前集出现信件、短信、聊天记录、书页、日记、邮件、报告、病历、通知、名单或屏幕文字，且其中内容影响人物知情、行动、证据、选择或后果时使用。装饰性文字不触发。

## 核心规则

推动剧情的文字信息不能只写在动作描述里让观众自行阅读。保留必要画面，同时让关键信息自然进入可听对白；即使遮住画面中的字，观众也应知道发生了什么。

画内文字也不能单独充当动作坐标。禁止只写“在‘某词’下画线、按指痕”“圈出‘某句’”“指着‘某名字’”来交代人物操作；观众看不见那些字，就不知道动作落在哪里、为什么落在那里。

## 转换方法

1. 先写人物看到、拿到或打开文字载体。
2. 只把推动当前行动的关键句转成对白：
   - 人物读出最关键的一句；
   - 人物用自己的话告诉现场另一人；
   - 另一人追问“上面写了什么”，持有人回答；
   - 收发双方在争执或确认中复述关键内容。
3. 长文字拆成“关键句—反应—追问—确认”，不要整段朗读。
4. 保持事实来源、持有人和知情边界；没有看到文字的人不能凭空知道内容。
5. 台词说出信息后，立刻接人物反应、决定或动作，不让对白变成孤立说明。
6. 指、圈、划、盖章或按指痕若没有后续作用，直接删除，不要为了代替画面文字硬造动作。标记会成为证据、选择记录或鉴伪手段时才保留：先在同一拍用台词说出所指事实，再用行序或刚念完的位置承接动作。不要在叙述中把引号里的文字当定位坐标。

## 例子

仅靠画面：

> 手机短信写着：“今晚十一点去西门，不要带顾川。”

转成现场对白：

> 沈砚盯着新短信，没出声。
>
> 顾川：谁发的？说什么了？
>
> 沈砚：让我十一点去西门。还说……别带你。
>
> 顾川：所以呢？你真准备一个人去？

文字充当动作坐标的错误写法：

> 沈砚在“明夜”与“三更”下各压一道指痕，随即收起抄页。

此处指痕没有后续作用，直接改成可听信息：

> 沈砚（低声）：明夜三更，淮河芦苇渡口。火油两桶，进中间那辆车。
>
> 他把还能辨清的内容复述完，收起抄页，转头望向南道。

## 复检

- 遮住画内文字，观众是否仍能听懂关键事实及其来源？
- 是否只说必要信息，没有把整封信、整页书或整份报告机械念完？
- 文字信息是否立即改变了人物的话茬、判断或行动？
- 删除叙述中引号里的文字后，指、圈、划线、盖章或按指痕的目标是否仍然清楚？不清楚即未通过。
