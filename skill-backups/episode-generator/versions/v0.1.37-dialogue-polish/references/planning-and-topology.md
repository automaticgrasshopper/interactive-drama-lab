# 情绪分支与拓扑门禁

本文件只在规划阶段读取。所有候选、情绪记录和审计均为私有缓存；拓扑冻结后不得进入单集写作包。

## 1. 情绪脊

用起、承、转、合记录五项：人物幻想、现实风险、现实落点、控制权变化、下一催化。

- 起：建立缺失、压制、装置和第一份可兑现幻想。
- 承：玩家行动产生可见收益或关系靠近，同时埋入由该收益造成的风险。
- 转：前面收益携带的风险落地，使关系、判断或控制权反号。
- 合：最终选择让人物夺回、交出或重新定义控制权，并进入不同价值结局。

至少有一次由玩家此前选择促成的有效释放。失败结局可以不翻盘，但失败必须由此前选择造成。

## 2. 第一反应淘汰

对开场钩子、首次释放、中段反噬和高潮解法分别提出三个可执行方案：

- 方案一必须淘汰。
- 方案二、三必须在事件、因果或代价上实质不同。
- 采用项必须依赖本项目已有题材、规则、关系、场景或道具。
- 上游锁定事件不可改时，比较三种场面执行方式，而不是改写事实。

候选审计只保存到拓扑冻结；下游只继承采用结果。

## 3. 从情绪脊开扇

每个互动必须同时通过两道门：

1. 行动门：玩家眼前至少有两个立即可执行、彼此互斥、符合当前认知的行动。
2. 情绪门：这些行动在关系、价值、代价、风险或控制权上通向不同方向。

选项使用“动词＋明确对象”。只有动作差异、没有情绪和状态差异的选择删除；只有情绪概念、没有可执行动作的选择重写。

按主要作用标记：

- 关键选择：改变主路线、关键资源、主要立场或结局开放条件。
- 情感选择：改变信任、承诺、关系或人物判断。
- 调剂选择：改变即时反馈、局部信息或人物态度，经过独立结果集后较快汇合。

标签不是配额。一处选择只按主要作用命名，不强制项目拥有调剂选择。

## 4. 开扇、差异与收扇

- 同一选择设置二至四个选项。
- 每个选项先进入自己的结果集，不得直接无差异汇合。
- 结果至少改变关系、信息、风险、资源、承诺、道具或行动权中的一项。
- 汇合只统一下一共同事件；尚未解决的差异必须进入人物态度、可用信息、权限、资源或结局条件。
- 重大路线应拥有连续差异事件；快速汇合路线也必须在结果集和后续承接中可见。
- 末段优先阶梯式开扇：先剥离一种价值结局，再对继续路线提出更深选择。上游明确要求一次终选，或阶梯会制造伪选择时，可以集中开扇并记录理由。

## 5. 一节点一集

只有同时满足以下条件才独立成集：

- 人物采取具体行动；
- 行动遇到阻力或需要判断；
- 结尾产生新事实、关系、得失、风险、选择或行动方向。

选择、选择结果、反馈、汇合和结局只要进入流程图，就是独立分集。每集只解决一个主要问题，可以包含多个连续场景。

## 6. 包子四检

每个节点逐项回答：

1. 具体事件：谁在什么地方做了什么，并产生什么结果？
2. 题材反差物：哪个改变局面的因素只在本项目规则下成立？
3. 题材内升级：结果如何沿同一规则继续升级，而不是靠道歉、巧合、突然事故或说明收口？
4. 催化或余波：下一集为何必然发生，或结局留下什么具体后果？

任一项只能写主题词、气氛词或作者评价时，该节点不通过。平情节可以存在于场内，不能独占一集或成为收口。

## 7. 拓扑验收

冻结前逐项确认：

1. 情绪事件先于因果事件，因果事件先于分集节点。
2. 一个节点对应一集，编号唯一连续。
3. 入口可达全部节点；非结局有后继，结局无后继。
4. 每个选择至少两个不同目标，且每个选项有独立结果集。
5. 汇合保留全部未解决差异。
6. 失败小结局由当前或此前选择造成。
7. 正式结局回收前面选择，并在所得、失去或价值判断上不同。
8. 每集通过包子四检，写清核心变化和下一催化。
9. 公开梗概与流程图由同一份拓扑生成。

通过后保存节点、边和结局条件的统一指纹；用户确认前不得进入单集写作。
