# 画内文字信息转台词

只在当前集出现信件、短信、聊天记录、书页、日记、邮件、报告、病历、通知、名单或屏幕文字，且其中内容影响人物知情、行动、证据、选择或后果时使用。装饰性文字不触发。

## 核心规则

推动剧情的文字信息不能只写在动作描述里让观众自行阅读。保留必要画面，同时让关键信息自然进入可听对白；即使遮住画面中的字，观众也应知道发生了什么。

## 转换方法

1. 先写人物看到、拿到或打开文字载体。
2. 只把推动当前行动的关键句转成对白：
   - 人物读出最关键的一句；
   - 人物用自己的话告诉现场另一人；
   - 另一人追问“上面写了什么”，持有人回答；
   - 收发双方在争执或确认中复述关键内容。
3. 长文字拆成“关键句—反应—追问—确认”，不要整段朗读。
4. 保持事实来源、持有人和知情边界；没有看到文字的人不能凭空知道内容。
5. 台词说出信息后，立刻接人物反应、决定或动作，不让对白变成孤立说明。

## 例子

仅靠画面：

> 手机短信写着：“今晚十一点去西门，不要带顾川。”

转成现场对白：

> 沈砚盯住新短信。
>
> 顾川：她说什么？
>
> 沈砚：十一点，西门。她还特意写了——别带你。
>
> 顾川：那你现在还打算一个人去？

## 复检

- 遮住画内文字，观众是否仍能听懂关键事实及其来源？
- 是否只说必要信息，没有把整封信、整页书或整份报告机械念完？
- 文字信息是否立即改变了人物的话茬、判断或行动？
