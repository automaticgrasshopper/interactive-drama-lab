# 单集场级锻造桥接

拓扑和生产卡冻结后、正文生成前读取。只负责把当前节点写成完整可读的连续场面，不规划拓扑，不新增设定，不另建校验体系。

## 一、写作护栏

先从生产卡提取四项：

```text
不可改：入口事实、核心结果、出口条件、选择后果。
必须演：触发事件、第一反应、关键行动、阻力、可见结果、人物余波。
允许调：普通连接动作、场数、对白措辞、不改变事实的时间压缩。
禁止加：新规则、新权限、新关键证据、新固定角色、巧合救援与突然认罪。
```

任何证据、权限、人物或道具在当前硬状态中没有来源，停止写正文并返回生产卡；不得用一句对白补出来源。

## 二、场级施工图

每场正文前只写以下九项：

```text
场次与地点：
开始状态：
本场唯一任务：
触发事件：
人物第一反应：
核心行动：
阻力与调整：
可见结果与人物余波：
场尾进入下一行动：
```

- 一场只承担一个主要任务；两个任务必须属于同一条因果链。
- 一集只有一个主要事件，最多带一个服务于它的次要事件。
- 一集出现三个独立重大结果时，返回生产卡前移、后移或拆分，不在正文中挤完。
- 日常场不强制争吵，但仍要有事件、反应、行动和结果。

## 三、连续戏写法

正文按连续因果写，不按动作和台词数量填模板：

```text
事件被感知
→ 人物依据当前认知与关系作出反应
→ 采取具体行动
→ 遭遇人物、环境、程序或信息阻力
→ 调整行动
→ 结果在现场显现
→ 关键人物对结果作出反应
→ 形成下一行动
```

重大结果不能由一句旁白、裁决、认罪、和解、蒙太奇或时间跳跃代替。象征物只能承接已经发生的关系选择，不能代替选择与对方反应。

## 四、正文前快速门

写正文前回答：

1. 本集是否只在解决一个主要问题？
2. 每个关键事实和物件是否在入口硬状态中存在？
3. 每场是否会产生一个可见结果？
4. 结果出现后，核心人物是否来得及反应？
5. 场尾是否真实形成后续节点入口？

任一项答不出，不进入正文。
