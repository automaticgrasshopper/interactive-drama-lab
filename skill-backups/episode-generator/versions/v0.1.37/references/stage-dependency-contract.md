# 阶段依赖与恢复契约

这条链同时约束模型调用与私有文件。reference 凭证证明当前步骤已装载指定说明；内容指纹证明下游读取的是未变化的上游。任一步缺失、失败或过期，控制器都不得领取下一步。

## 固定链路

```text
upstream
→ emotional-spine
→ causal-graph
→ topology
→ episode-writing（逐集串行）
→ dialogue-polish（紧跟当前集）
→ continuity-review（全剧）
→ final
```

不存在 `episode-map`：分集拓扑里的每个 `episode-NNN` 本身就是一集。选择边只能从当前集指向目标集；选择结果、反馈、汇合和结局节点也都是独立分集。

## 阶段产物

- `upstream`：冻结人物、关系、世界规则、资产名、结局要求。
- `emotional-spine`：私有情绪事件。至少覆盖钩子、首次收益、中段反噬和高潮解法；强度不足时同时增强压力、行动和不可逆代价，不能只改数值。
- `causal-graph`：每个情绪事件必须落实为人物行动、阻力、结果和下一催化；不得用“剧情需要”作因果。
- `topology`：直接生成 `episode-NNN`。每集含标题、梗概、类型、后续分集；选择集的每个出口写清不同后果，汇合集保留来路差异。
- `episode-writing`：一次只写一集；输入只含本集梗概、可靠前置事实、正式资产与直接后续入口。
- `dialogue-polish`：对刚写完的一整集做一次人话润色，替换初稿。
- `continuity-review`：所有分集完成后只检查前后事实。
- `final`：仅组装各集梗概、分集流程图和完整剧本。

## 长度依赖

第一集口语化定稿的去空白可见字符数写入私有清单，成为全剧长度基准。后续每集必须为基准的 90%—110%，每场至少 350 个去空白可见字符。长度不合格只阻断当前集，不使已完成前集失效。

## 中断恢复

每一步保存输入指纹、输出指纹和状态。继续时：

- 已完成且上游指纹未变化的步骤不重做。
- `待写作` 从当前集写作开始。
- `已写作` 从当前集整场人话润色开始。
- `已口语化` 跳到下一集。
- 全部已口语化但全剧未完成事实检查时，从连续性检查开始。
- 上游内容变化时，只从最早受影响的阶段向后失效。

最终三个公开文件先在私有 staging 组装，再整体替换。缓存、情绪脊、因果链、长度基准、事实摘要、问题单和状态凭证不得进入公开内容。
