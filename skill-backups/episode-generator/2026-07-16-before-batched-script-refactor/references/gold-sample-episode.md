# 真人分集剧本金标：《盛世天下·女帝篇》“刘熙的条件”

本文件只在分集规划师需要确认真人制作剧本如何组织人物出场、信息升级、多轮交锋、具体代价和互动选择时读取。

语料来源：后台提供的《盛世天下：女帝篇》序集互动剧本。以下保留一段连续原始场景作为金标，不改写人物、台词和互动选择。学习时只提炼结构与写法，不复制人物、世界观或剧情内容。

## 使用原则

- 观察人物如何在一句句攻防中交代背景，而不是模仿古装词汇。
- 观察信息如何逐级升级：出现、试探、否认、举证、亮底牌、开条件。
- 观察普通反应句如何连接长信息，使台词不是连续设定发布。
- 观察互动选择如何从场内冲突和具体代价自然长出。
- 不机械复制原场景的情节、人物和用词。

## 原始场景

【场景：感业寺大殿，刘熙的条件】

刘熙持花簪现身，红衣夺目。

【刘熙】（现身笑）“伍元照，别来无恙啊。”

【伍元照】（惊）“刘熙！”

【刘熙】（挑眉）“怎么，我来看你，很吃惊？你知道是谁把我从牢里放出来的吗？是高扬——你曾经最好的朋友啊。”

【伍元照】（不信）“不可能！”

【刘熙】（拽衣）“如若不是高扬，我如何穿得这身尚宫衣裳？她特命我来感业寺，好生对待你。”

【伍元照】（震）“指使她们欺辱我的，竟然是高扬……”

【刘熙】（淡嘲）“如今时过境迁了，你却还对我如此念念不忘。若非你父亲当年的诬陷，我父亲怎会郁郁含恨而终？你父亲欠我们刘家的，都该由你来还。”

【伍元照】（斥）“当真是疯了！”

【刘熙】（反诘讥）“疯？你的那些痴心妄想，难道不比我更疯吗？”

【伍元照】（驳）“你在胡言乱语些什么！”

【刘熙】（诵）“自盛安一别，已历数月。感业寺中虽清苦，尚可度日。若得机缘，愿与君游览自由之天地。”

【伍元照】（惊）“你是怎么知道的？！”

【刘熙】（笑）“来探望好姐妹，自然要先去她的闺房拜访一番喽。你放心，你与魏王那些信件，我都替你好好收着了。我竟不知，你与魏王还有这等交情。”

【刘熙】（转冷）“只可惜，魏王失势，想要落井下石的人势必蠢蠢欲动。今日可是你给了他们铲除魏王的理由。没想到，你到死还要拉魏王为你陪葬。”

【伍元照】（怒）“刘熙，你到底要做什么！”

【刘熙】（笑）“其实，我也不是不念旧情之人。只要你让我用这支花簪，在你的额头上刺一朵牡丹，我高兴了，便放了那魏王一条生路。”

我高兴了，便放了那魏王一条生路。你决定……？

【选项：刘熙的条件】

1. “夺下花簪，除掉刘熙” → 进入夺簪搏斗。
2. “向她求饶，让她别划脸” → 进入失败结局“人性化熙姐”。
3. “不再挣扎，保全魏王” → 进入失败结局“宿命般的牡丹”。

## 结构拆解

### 一、人物出场明确

刘熙先以“红衣、花簪、尚宫衣裳”出现，伍元照立即叫出她的名字。观众先知道来的是谁，再进入旧仇和现实威胁。

### 二、人物目标清楚

- 刘熙要报复伍元照，并利用书信控制她。
- 伍元照要保护自己的离寺计划和魏王。

目标冲突让每句台词都有明确用途。

### 三、信息逐层升级

```text
刘熙出现
→ 声称由高扬放出
→ 伍元照否认
→ 刘熙用尚宫衣裳举证
→ 旧日父仇被重新提出
→ 刘熙背出书信内容
→ 证明信件已经落入她手中
→ 魏王安危成为现实代价
→ 刘熙提出花簪刺脸的具体条件
→ 玩家选择
```

重要信息不是一次倒完，而是每次在伍元照反驳后，再加一层更硬的证据。

### 四、普通反应句连接长信息

“不可能”“当真是疯了”“你到底要做什么”都是简短、直接的反应。它们让刘熙的长信息有接点，也让权力变化被观众感知。

### 五、权力发生变化

伍元照起初只是惊讶，随后不断否认；刘熙依次拿出身份、旧仇、书信和魏王安危，逐步夺走主动权。场景结束时，伍元照被迫在多个代价之间做选择。

### 六、代价具体

选择不是抽象的“信任或不信任”，而是：

- 夺簪反抗，进入搏斗风险。
- 求饶保脸，接受屈辱并可能失败。
- 放弃抵抗，牺牲自己保全魏王。

玩家可以立刻理解每个选项在赌什么。

### 七、互动从戏中自然长出

选择点出现在刘熙提出具体交易之后。玩家不是为了“增加互动”而选，而是必须回应已经形成的现实困局。

## 金标验收标准

- 新人物先完成出场和身份确认，再展开背景关系。
- 每个角色当下目标明确，台词服务于目标冲突。
- 信息逐层升级，不一次倒完，也不靠旁白解释关键证据。
- 长信息之间有普通反应句承接。
- 场内至少发生一次明显权力变化。
- 代价具体，观众立即知道接受与拒绝各会失去什么。
- 互动选择由场内冲突自然产生，每个选项有清晰后果方向。
- 制片分行没有切断对话攻防和因果顺序。
