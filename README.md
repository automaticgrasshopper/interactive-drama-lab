# 互动影视节奏工作台 (interactive-drama-lab)

> 影视互动游戏「故事节奏」核心资产：大纲编剧台、场景分镜台、可玩游戏三合一工作台，加设计规则书、导演分镜方法与配套 skill。

最后更新：2026-07-20

## 快速启动（推荐）

双击仓库根的启动脚本，会起一个**仅本机访问**的本地前台并自动打开工作台（关窗即停）：

- macOS：`启动.command`
- Windows：`启动.bat`（需已装 Python 3；无 Python 时脚本会提示）

> **固定端口 8000，不自动顺延。** 因为浏览器记录（localStorage）按“协议+域名+端口”隔离，端口一变就是另一份存储、旧记录读不到。锁死 8000 保证每次都落在同一处、记录永远都在。若 8000 被占，脚本会报错提示（多半是重复开了窗口）而不静默换口。

启动后默认打开 `h5/index.html`（三合一外壳）。也可直接单独打开各 H5，但数据包读写/记录共享需走 `http://`、不要用 `file://`。

> 启动脚本跑的是 `serve.py`（而非裸 `python -m http.server`）：生成记录和补图会自动写进 `h5/datapacks/`；Git 提交与推送统一在「生产后台」管理。

## H5 三合一工作台

`h5/index.html` 是**外壳**：左侧竖排四个入口（📝 大纲编剧台 / 🎬 场景分镜台 / 🎮 游戏界面 / ⚙️ 生产后台），右侧 iframe 切换。

- **懒加载 + 常驻**：页签首次点击才建 iframe，之后不重载、切来切去不丢状态。
- **跨台跳转无缝化**：同源下 hook 子页 `window.open`，节奏台→分镜台、分镜台→游戏不再弹新标签，而是切页签+重载目标（照旧走 localStorage 传数据），原三个 H5 零改动。
- **自动存档 + 统一推送**：编剧台与分镜台的生成记录会自动写入数据包；Git 提交和远程推送统一从「生产后台」执行。

| 路径 | 是什么 |
|---|---|
| `h5/index.html` | 三合一外壳（左侧页签导航）。 |
| `h5/影视互动游戏故事节奏验证.html` | **大纲编剧台**。管结构+节奏+剧本；支持上传文稿与参考图，自动识别创意种子/详细需求/素材约束/完整剧本四档输入口径，无需手动切换模式；分集工坊动态跟随当前 `episode-generator` 规范，但由工作台独立完成上游题材与资产准备。v0.1.43 采用情绪脊状态拓扑：情绪脊→玩家动作与状态写入→独立结果集→逐集相邻因果拍写作→结构化冷读理解门→事实、因果、首次出现与人话对白检查。页面会自动发现当前项目的后台任务，刷新或跨台恢复后继续显示安全的公开进度。分集流程图支持按钮、Ctrl/⌘+滚轮缩放与一键适配。 |
| `h5/分镜工作台.html` | **场景分镜台**。从「剧本/一场戏」出发，**「一键生成」全流程**：分镜表 / 分镜提示词（LLM）→ 人物三视图 → 场景图 → CG 分镜（锤点驱动图生图）→ 故事版；已有图跳过不重生、停止键分阶段可中断；出图即压缩（720p+WebP0.85）；CG 图存 IndexedDB，可**导入游戏**（台词+CG 注入）。导演分镜执行卡与图像骨架在生产后台集中查看，与 skill 同源。<br>**画风 Preset + 统一视觉导演规则**：默认选中“智能推荐”，会按剧本题材、时代与氛围自动锁定一套最终 Preset；也可手动选电影级写实、新黑色悬疑、哥特悬疑、复古电影胶片、新中式武侠、赛璐璐动漫、风格化 3D 奇幻、像素叙事 8 套画风。选定后自动编译静帧画风、视频时序稳定、负向防污染与保留项，记录和案例包固化当时 Preset 快照。<br>**分批制作（同剧本合并一条记录）**：左侧选几场生成、再选几场生成，自动合并到同一条记录（按绑定故事/集号归一，镜号全局重编不冲突，同场次重生会覆盖）——后生成不覆盖前面、且能预览之前已做镜头，整部一次导入游戏。左侧场次支持**全选**；主生成按钮文案随选中数变（选部分=批量生成 N 场、全选/未选=生成全部）。<br>**记录存原始输入**：载入记录会把剧本 JSON 与选中场次回填左侧，不用再从上游重点。<br>**分镜提示词页**：当提示词数少于分镜表镜头数（模型输出被截断）会红字告警；只在有待出图时才显“生成分镜图”按钮。<br>**导入游戏用上全部分镜图**：一个节点多张分镜图不再只取第一张，而是按台词行均匀铺开、随剧情逐步切换（每张图写成 `@bg <label>#i` 插在对应台词前）；图比句多时末句后连续补切，保证每张图都用上、与剧本相适配（游戏引擎 `@bg` 原生支持，无需改引擎）。 |
| `h5/互动影视游戏.html` | **游戏界面**（React 构建单文件，源码在 Kian app 模块）。可玩的互动影视游戏，吃分镜台导出的剧本；带 CG 显 CG、无则纯文字。主菜单左上角：删档 + 「日志」toggle（默认关，开启才在顶部出调试日志条）。 |
| `h5/生产后台.html` | **生产后台前端**。配置 OpenRouter Key、生成/校验模型和本机保存策略；按“本次 / 全部任务”查看本次生成及未入库的本地记录，或包含仓库只读归档的完整任务。失败或停止且已有拓扑断点的生产任务可点击“继续”；新版任务会保留执行组及九级状态，已完成并回写的组不会重复生成。运行中任务可停止，本地任务删除有确认保护；仓库推送不在网页操作区提供，网页这里只保留精准重启。Key 只写入本机 `.runtime/`，不进入 Git。 |
| `backend/` | **本地后端**。项目与任务持久化、OpenRouter 长请求代理、动态装载当前 `episode-generator` reference bundle；按集保存“待写作 / 已写作 / 已口语化”断点，完成整集写作和一次人话润色后再推进，最后只做前后事实连续性检查与最小修复。保留长 JSON 重试保护、内部脱敏诊断、停止、续跑和任务管理；页面刷新不终止生产，重开后可恢复状态。`serve.py` 作为兼容启动入口，当前健康接口版本为 8。 |

## Skill（以 Codex 为主，放进 `~/.codex/skills/` 即可用；均自包含、可独立运行）

> `skill/` 中的 Skill 是独立运行规范；`h5/影视互动游戏故事节奏验证.html` 只是实验与顺路校验平台，不是 Skill 的运行入口，也不决定 Skill 的最终行为。

| 路径 | 是什么 |
|---|---|
| `skill/outline-generator/` | 【新管线①大纲】故事描述/体量/视角/结局数/画风 → 互动影游大纲企划（含附录叠加层：三条红线/决策卡/结构信封＋PAD情绪脊）。 |
| `skill/episode-generator/` | 【新管线②·分集规划师】读取游戏企划、角色描述、场景描述和道具描述；版本由 `reference-manifest.json` 统一声明，后台动态跟随；通过确定性 reference 装载、私有缓存、执行组生产和分层复核完成分集梗概、完整流程图与完整剧本。公开层只保留 `episode-synopsis.md`、`episode-flowchart.svg`、`episode-script.md`，九字段在内存中交给下游。 |
| `skill/故事结构专家/` | 【管线①源头】题材/描述/时长/结局数 → 结构骨架（题材标签/大纲/分集节点与分支/情绪节拍/结局分配）。只出结构与节奏，不填台词/分镜。输出骨架 JSON → 喂给剧本实例化专家。 |
| `skill/剧本实例化专家/` | 【管线②填肉】吃结构骨架 → 实例化为可拍剧本（人物全状态卡/场景日夜卡/道具两级表/逐节点分场剧本）。只填肉不改骨，不出分镜。 |
| `skill/导演分镜故事版拓展能力/` | 【管线③分镜】把一场戏翻成逐镜头分镜＋可喂 AI 视频的分镜提示词（导演视觉语法）。 |

| `skill/互动影像资产图像提示词生成/` | 【旁支·资产图】把已确认/用户编辑过的资产描述（人物/场景/道具）转成英文 16:9 生图提示词（三视图 model sheet / 场景概念图 / 道具参考表 / 参考图遵循 / 负向 / 资产 ID 绑定）。只出图像提示词、不执行生图。 |
| `skill/角色三视图设定表生成能力/` | 【旁支·人物图】把人物设定翻成三视图生图提示词（固定版式锁脸防漂，多状态）。 |

> **新分集管线**：`outline-generator`（游戏企划）→ `asset-designer`（角色/场景/道具描述）→ `episode-generator`（分集规划、完整剧本、互动节点）→ 下游故事板与互动程序。正式上下游字段统一使用中文；内部规划不扩张为传参字段，分镜所需的其它明细由下游根据梗概、剧本、冲突和前后节点自行拆解。
