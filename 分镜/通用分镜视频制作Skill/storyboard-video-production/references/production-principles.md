# 通用分镜与视频制作规范

本文件保存影响分镜质量和生产可靠性的非显然规则。它不绑定某个项目字段、资产系统或视频模型。

## 1. 三种表示必须分开

### 剧本 Beat

叙事层的最小变化：新事实、行动结果、关系变化、情绪转折、选择或声音事件。Beat 决定“必须讲到什么”。

### Storyboard Clip

一个明确时间点的代表性定格状态。它决定“观众在关键时刻看见什么”。一个 Clip 不应同时包含动作的起点、过程和终点，也不应让同一角色同时出现在两个时间位置。

### Video Shot

一次连续生成能够自然承载的声画过程。它决定“这段内容如何随时间发生”。一个 Shot 可以覆盖多个相邻 Clip，但一个 Clip 只能映射到一个 Shot。

这三者混用时，常见结果是故事板过载、视频动作跳变、台词截断或镜头数量机械膨胀。

## 2. 先导演，后提示词

提示词不是创作判断的容器。写 Prompt 前先确定：

- 场景真实地理、入口出口、固定陈设、不可穿越物和可行走区域；
- 人物目标、权力变化、站位、移动路径、视线和动作对象；
- 对话轴线、摄影机默认所在侧和银幕运动方向；
- 道具归属、状态变化和交接；
- 对白、心声、环境声、动作声、音乐或沉默的连续范围；
- 每个节拍需要的景别、构图和摄影行为。

最终 Prompt 只表达可拍、可演、可听或可验证的结果，不保留“为了表现”“观众需要理解”“象征着”等分析说明。

## 3. Clip 生图前门槛

在锁定故事板前逐项检查：

1. 剧本中的必要 Beat 是否都有 Clip 承载。
2. 每个 Clip 是否只有一个明确可见状态。
3. 台词、动作和反应是否能被某个下游 Shot 自然承载。
4. 相邻 Clip 的人物数量、站位、朝向、视线、道具和空间是否连续。
5. 是否存在需要完全不同机位、跨轴或重新摆演员才能同时成立的内容。

发现问题应在故事板生图前拆 Clip 或修正导演规划。不要等视频 Prompt 阶段用额外动作或魔法转场补救。

## 4. Shot 边界

以下情况通常构成硬边界：

- 时间、地点或主观视角跳变；
- 摄影轴线、摄影机所在侧或画面逻辑必须切换；
- 人物集合、空间位置或关键道具状态无法通过连续物理过程成立；
- 必须换独立机位或重新布置演员；
- 剧情要求通过切镜隐藏、揭示、压缩时间或落下互动节点；
- 完整台词、动作和反应超过目标模型的自然生成能力。

画格变化、景别变化、切到倾听者或连续台词本身不自动形成 Shot 边界。一个主机位通过兼容的推、拉、摇、移、跟随、焦点变化或人物进出画完成时，可以保持为一个 Shot。

## 5. 自然时长

不要先选一个固定时长，再往里填内容。建议时长来自：

1. 角色按实际语气说完整台词或心声的时间；
2. 物理动作和空间移动的必要时间；
3. 必需的倾听、呼吸、沉默和情绪落点；
4. 可以自然并行发生的声音、表情、手部动作和小幅移动。

声音轨和动作轨中较长者构成基础时长，再加入只能串行发生的反应或转场。没有新信息、动作或情绪变化时应缩短，而不是用剧本外走动填满模型上限。

## 6. 声画双时间轴

画面和声音分别规划：

```text
画面时间轴：环境 → 机位/运动 → 动作/表情
声音时间轴：对白/心声 → 环境底声 → 动作声 → 音乐/沉默
```

两条轨道覆盖相同总时长，但分段边界可以不同。一句对白跨越多个画面状态时只出现一次，保持完整句意、自然音色和连续时段。画面切换不能让台词重复、截断或重启。

## 7. 连续性状态链

每个 Shot 至少记录以下开始与结束状态：

- 场景、时间、天气、光源方向和固定陈设；
- 摄影机所在侧、对话轴线和银幕方向；
- 角色站位、朝向、身体/服装状态；
- 道具归属、开合、破损或其他关键状态；
- 持续对白、环境底声或动作声。

同场连续时：

```text
Shot N 的结束状态 = Shot N+1 的开始状态
```

明确转场时只继承剧情要求跨场保留的人物身体状态、服装、道具、关系或持续声音。

## 8. 高风险场面

### 多人对话

先确定谁控制当前节拍，谁说话、谁倾听、谁隐藏信息、谁反应。不要平均分配特写。群像镜头负责建立联盟与权力变化，单人镜头只在角色获得或失去权力时使用。

### 进出门和跨空间移动

写清门的初始与结束状态、角色位于哪一侧、合法路径、离场后空出的空间以及留下者的反应。避免把关门生成成开门，或让人物穿过实体。

### 近身动作、救援与交接

固定执行者、协助者、观察者和承受者的职责；说明谁移动、谁保持不动、动作对象与道具从谁手中交给谁。不能把不同时刻的位置塞进同一画面。

### 文字和证据

按“普通语境 → 线索细节 → 人物反应 → 新意义”组织。精确文字不可靠时使用预制道具、角色朗读关键词或对白确认，不让生成模型临时创造大段关键正文。

## 9. 表演必须可见

抽象情绪要落到可以表演的外部状态，并给出方向和强度，例如：

- 眼神焦点和移动；
- 呼吸速度；
- 眉眼、嘴角、下颌和肩颈张力；
- 手部停顿或抓握；
- 身体距离、转身和重量变化。

只选服务当前节拍的少数信号。除非剧本确有爆发，不把每种情绪都写成高强度表演。

## 10. 故事板作为干净 Reference

故事板可包含编号、标签、参考栏或空间示意，但最终电影画格应保持干净：

- 编号和短标签放在画格外；
- 箭头、路线、机位符号和轴线只进入专门示意区；
- 电影画格内不出现界面、说明文字、红框或运动轨迹；
- 下游视频明确排除整张故事板页面、多画格分屏、边框、标签和示意符号进入成片。

## 11. Prompt 编译建议

若目标模型没有自己的固定格式，可使用：

```text
参考：<故事板版本、来源 Clip、真实可用资产>
画面时间轴：
[开始-结束]
- 场景与环境：...
- 景别与镜头：...
- 动作与表情：...
台词与声音：
[开始-结束]
- ...
视觉风格：<项目锁定风格或用户要求>
必要约束：<身份、空间、道具、禁止项>
```

时间片数量由实际可见状态变化决定，不固定套用三段式或其他模板。目标模型有专用字段、引用语法或音频规则时，应转换到该模型的权威格式。

## 12. 并发与失败恢复

在启动并行任务前：

1. 完成整集 `Clip -> Shot` 唯一映射。
2. 建立所有 Shot 的稳定编号、顺序和空结果槽位。
3. 完成连续性链。
4. 给每个任务一份不可变 Shot 记录。

结果必须按 Shot ID 写回。任务失败时保留原槽位为空，不删除、不追加、不重排；其他成功 Shot 不受阻塞。只有导演规划、故事板或连续性状态改变时，才扩大重试范围。

## 13. 最小验收清单

- 所有必要剧本 Beat 都有可追溯的 Clip。
- 每个 Clip 是一个定格状态，且只映射到一个 Shot。
- 每个 Shot 只使用相邻 Clip，边界符合物理、摄影、声音和模型能力。
- 台词、动作、反应与建议时长自然匹配。
- 相邻 Shot 的人物、空间、道具、轴线、光线与声音可以连续。
- Prompt 不包含内部分析，引用均真实可用并符合目标模型语法。
- 并发结果按稳定 ID 写回，失败不会改变列表长度或顺序。
