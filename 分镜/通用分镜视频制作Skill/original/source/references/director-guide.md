# 导演指南

本指南只提供同一集内的导演方法。`SKILL.md` 是唯一业务流程，负责资产预检、故事板对话展示、阶段切换、并发、占位和结果写入；本指南不重复调度这些步骤。

`分集剧本` 是导演工作的语义起点。先完整理解剧本，再建立场景连续性和摄影方案；不得先设定空间或镜头，再反向压缩、改写或遗漏剧本内容。

## 1. 阶段边界与调用方法

| 阶段 | 本阶段决定 | 本阶段不决定 |
|---|---|---|
| 剧集故事板 | 剧情事件、场景划分、场景固定设定、人物调度、摄影轴线、Clip 数量与顺序、代表性定格画面、关键声音落点 | Shot 分组、视频时长、动作全过程、时间戳 |
| Shot 拆分 | 相邻 Clip 的组合与边界、剧本覆盖、自然时长、声音连续性、Shot 间承接与交接 | 改写剧情、重排 Clip、重新设计场景或人物调度 |
| 视频 Prompt | Shot 内画面和声音时间轴、摄影运动、动作过程、表情强度、Reference 与必要约束 | 修改 Shot 边界、增删剧情、重新规划故事板 |

### 1.1 剧集故事板阶段：从剧本形成导演规划

按以下顺序执行：

1. **完整解读分集剧本**：按原顺序列出场景、剧情事件、人物目标、关键台词/心声、关系变化、因果线索、情绪转折和互动节点。不得用梗概代替完整剧本，也不得为了画面简洁省略内容。
2. **划分场景与转场**：确认哪些内容处于同一时间、地点和视角，哪些属于剧本明确的地点、时间或视角变化。
3. **建立场景固定设定**：只在场景划分完成后，为每个场景确定空间结构、入口出口、固定陈设、不可穿越物、时间天气、光线、对话轴线和摄影机默认所在侧。同一场景的相邻 Clip 沿用这套设定；人物站位、身体状态和可移动道具归属由各 Clip 单独记录。
4. **规划戏剧与人物调度**：使用第 2、3、5、6、7 节确定人物目标、权力变化、合法移动路径、站位、视线、动作对象、道具交互和必要俯视空间示意图。
5. **规划声音与摄影覆盖**：先按第 4 节梳理完整对白、心声、环境声、动作声、音乐和必要沉默，再按第 9 节选择景别、机位和画面覆盖。故事板只记录关键声音落点，不设置声音时间戳。
6. **形成 Clip 规划**：按第 8 节把整集转换为足以完整讲清剧本的代表性定格状态。每个 Clip 只表现一个明确时间点，记录关键剧情发展、当前可见状态、必要台词或声音落点、景别与机位，以及与相邻 Clip 的连续关系。

本阶段产出完整导演规划与有序 Clip 规划，交给 `storyboard-prompt-rules.md` 组装故事板提示词。不得感知后续 Shot 如何组合，也不预测视频秒数。

### 1.2 Shot 拆分阶段：决定连续内容如何承载

本阶段同时读取 `分集剧本`、完整导演规划、当前剧集故事板和拆分指南，按以下顺序执行：

1. 将每个 Clip 重新对齐到分集剧本中的事件、台词/心声、关系变化、线索、情绪转折和互动节点。
2. 沿用故事板已经确定的场景固定设定、人物调度、道具状态、摄影轴线和声音关系，不重新导演。
3. 标记时间地点跳变、视角切换、物理状态不连续、自然时长上限或剧本明确切点等硬边界。
4. 在硬边界之间，按连续戏剧目标、物理过程、摄影兼容性和声音连续性组合一个或多个相邻 Clip。画格变化、景别变化或切到倾听者本身不自动构成 Shot 边界；若相邻 Clip 之间必须硬切到独立机位、改变摄影机所在侧或重新布置演员位置，则在切换前结束当前 Shot。单个 Clip 不得包含需要独立机位、重新布置演员或多个互不兼容定格状态的内容；这类问题必须由生图前 Clip 承载预检提前拆开，不能留到 Shot 阶段再重画故事板。
5. 根据完整台词、动作、反应和必要停顿计算自然时长；承载不下时拆成更多 Shot，不删减剧本。
6. 按 Shot 顺序建立同集连续性链，写清每个 Shot 的承接状态和交接状态，再进入并行 Prompt 生成。

本阶段只决定“哪些相邻 Clip 由同一段视频承载”，不修改 Clip 数量、顺序、定格状态或导演方案。具体字段和时长方法以 `episode-storyboard-to-video-split-plan-guide.md` 为准。

### 1.3 视频 Prompt 阶段：把 Shot 转成执行指令

本阶段读取完整导演规划、当前故事板和当前 Shot 拆分结果，按以下顺序执行：

1. 从当前 Shot 的承接状态开始，确认需要到达的交接状态和必须完整覆盖的剧本内容。
2. 将场景环境、摄影、动作和表情组织成连续画面时间轴；每个 Shot 优先使用一个主机位和与其兼容的连续摄影运动，不得改变既定场景、轴线、人物调度或道具归属。相邻 Clip 之间需要硬切到独立机位或重新布置演员时，返回 Shot 拆分阶段建立新 Shot。单个 Clip 内出现这种切换属于生图前承载预检必须排除的规划错误，视频 Prompt 不得通过复用来源 Clip、临时改镜或重新生成故事板来补救。
3. 将完整台词、心声、环境底声、动作声、音乐和静默组织成独立声音时间轴。声音可以跨越画面切换，不因画面分段重复、截断或重启。
4. 写入实际使用的故事板、角色、道具和音色 Reference。
5. 只保留可拍、可演、可听或可验证的直接指令，删除剧本分析、拆分理由、风险推理和导演解释。

本阶段只决定“当前 Shot 具体如何发生”，不修改 Shot 边界或补写剧情。格式、引用和检查方法以 `episode-storyboard-to-video-split-plan-guide.md` 为准。

## 2. 关键方法：空间与物理调度

先确定场景真实地理，再安排人物和摄影机。墙、门、桌、床、沙发、柜台、车辆、栏杆、人群和危险区域均视为实体边界，不得穿越。

规划时写清：

- 入口、出口、主要活动区、固定障碍和可行走通道。
- 每个角色的当前区域、必要移动路径、动作对象和保持不动的观察者。
- 摄影机所在侧、可移动范围，以及大型物体如何承担距离、权力或遮挡关系。

长桌会议、床边救援、多人围绕同一主体、门口进出、多房间移动或复杂反打容易漂移时，先规划俯视空间示意图。俯视图只标空间边界、合法区域、必要路线节点、摄影机位置、拍摄类型和对话轴线；其中的箭头、路线和机位符号不得进入故事板电影画格或最终视频。

## 3. 关键方法：轴线与视线

对话前建立关系轴线，运动前建立移动方向。除非剧本需要可读的轴线转换、转向、反转或迷失，连续画面保持摄影机在轴线同侧、人物视线相对、银幕方向一致；绕过障碍时保留可理解的中间状态。

构图服务权力关系：俯拍削弱，微仰拍强化权威或威胁，居中构图表现控制或困局，负空间表现压力或缺席，前景遮挡表现监视或情感阻隔。只选与当前节拍直接相关的表达，不堆叠效果。

## 4. 关键方法：对话与声画关系

对话不只是文字。镜头应展示说话、倾听、隐瞒、反应和打断，并把“声音持续多久”与“画面何时切换”分别规划。

执行方法：

- 先为每句对白、心声和重要声音确定连续时间范围，再选择这段声音覆盖哪些画面。
- 对白开始时不强制停留在说话者；已经建立说话者后，可以切到倾听者、道具、环境或第三人的反应，同时让原声音继续。
- 画面切换不重启台词。跨切换的同一句台词在声音时间轴中只出现一次，并保持完整句意、自然语速和连续音色。
- 声音可以先于对应画面进入，也可以在画面切走后短暂延续，但必须服务于明确的注意力转移、反应或转场。
- 同一场景的环境底声应保持连续；只有地点、时间或剧情状态确实变化时才改变。
- Shot 边界尽量落在一句完整台词、一个明确声音事件或自然停顿之后；除非有意制造打断，不从中间截断不可分割的台词。

覆盖先建立人物距离和地位，再按戏剧重心选择说话者、倾听者、双人关系、道具插入或反应特写。不要逐句机械切镜，也不要只拍说话者。

| 对话状态 | 画面重点 |
|---|---|
| 谈判或审问 | 保留空间等级、桌面或证据；用静止、克制推近、手部和物件声表现权力 |
| 告白或说服 | 从回避、遮挡或距离开始，关键处转向干净单人镜头并保留倾听者沉默 |
| 争吵 | 情绪越线后再加快切换，让打断与移动或道具动作重叠，同时保留空间关系 |
| 威胁 | 强势者保持克制，用低角度、遮挡、阴影和出口关系制造压力 |

## 5. 关键方法：多人调度

三人以上场景不要平均覆盖所有人。决定谁控制这个节拍。

有用调度模式：

- 三角形：三人之间的稳定冲突，通过视线和站位转移权力。
- 桌边横线：正式等级、听证、董事会、家庭对峙。
- 圆形：仪式、联盟、群体压力、社交陷阱。
- 分裂群体：两派、隐藏忠诚、公共与私人冲突。
- 前景见证者：一人观察，另外两人说话，制造怀疑或审判感。

执行方法：

- 先建立所有人在场，然后跟随该节拍的情感主人。
- 用群像镜头展示联盟变化。
- 只有角色获得或失去权力时才使用单人镜头。
- 避免随机给每个人特写。
- 标明谁在说话、谁在倾听、谁在隐藏信息、谁默默反应。
- 高风险多人定格只列本帧应当可见的角色；每个命名角色只记录一次当前站位、朝向、视线、动作对象和职责。

人群场景：

- 识别主角穿过人群的路径。
- 背景运动用作压力，而不是视觉噪音。
- 通过服装、光线或运动保持主角可读。
- 不要让群演遮挡必要故事信息。

## 6. 关键方法：情绪到可见表演

抽象情绪必须落实为画面可见的身体状态，并同时给出方向和强度。只选择与当前节拍有关的眼神、呼吸、眉眼嘴角、肩颈、手部、身体距离、光线、构图或运动，不堆叠全部手段。

| 情绪状态 | 优先表达 |
|---|---|
| 平静紧张 | 静态或缓慢推近、受控负空间、轻微呼吸和手部张力 |
| 恐慌急迫 | 较短覆盖、跟拍或克制手持、前景障碍、急促呼吸与脚步 |
| 悲伤孤立 | 较宽空间、保留反应、柔和光线和克制运动 |
| 怀疑警惕 | 遮挡、门框或局部反射、先反应后解释、细小异常插入 |
| 亲密犹豫 | 缩短人物距离、柔和高光、眼神、呼吸和手部停顿 |
| 权威压迫 | 居中或微仰、实体障碍、强势者少动、弱势者承担更多移动 |
| 揭示 | 先隐藏信息，再用道具、焦点或受控推近揭示，随后落到反应 |

## 7. 关键方法：高风险事件

### 救援、搀扶和多人近身

- 先固定执行者、协助者、观察者和被救助者的空间关系，每个命名角色只承担一个当前职责。
- 故事板只选择一个定格状态；角色从协助转为远处观察时使用后续 Clip，不在同一画格保留两个位置。
- 优先使用能看清相对位置的侧面或三分之二中景；长距离绕行、身体接触和道具交接必须沿合法路径完成。
- 医疗处置保持克制、非血腥和物理可行，用身体状态、呼吸恢复与他人反应交付结果。

### 进出门与离场

- 区分移动路径、告别交换和留下者独处反应；内容复杂时分别用不同 Clip 或 Shot 承载。
- 单个故事板画格只保留角色当前所在位置。角色离场后的画面中，原位置为空，留下者反应发生在门已关闭之后。
- 视频表现开关门时写清门的状态、动作方向和角色所在侧，避免把关门生成成开门。

### 文字与证据线索

- 先按“普通语境 -> 线索细节 -> 人物反应 -> 新意义”组织，不让文件或屏幕独自承担剧情。
- 精确文字重要时优先使用预制实体道具；动态画面重点表现翻页、指尖停住、握紧道具、视线和呼吸变化。
- 无法可靠呈现精确文字时，由角色念出关键词或通过对白确认含义；避免生成大段假正文、扁平文字卡或依赖反光读取文字。

## 8. 关键方法：剧集故事板 Clip 规划

Clip 规划只负责把完整剧本讲清楚，不考虑后续 Shot 拆分或视频秒数。按铺垫、入场或第一动作、压力、转折、落点组织整集，但 Clip 数量由实际剧情状态决定，不固定模板。

每个 Clip 写清：

- 稳定编号、关键剧情发展和观众需要获得的新信息。
- 实际存在的关键台词或心声；没有时不强行添加。
- 一个明确时间点的可见定格状态，以及对应景别、机位和声音落点。
- 相对于前后 Clip 的人物、道具、空间、视线和摄影连续关系。

关键揭示、冲突升级、关系变化和互动选择应获得足够的代表状态；纯过桥、单一插入和短反应只保留必要定格。不要用重复状态抬高分量，也不要因版面限制压掉剧情。

心理活动必须具有外部触发、完整心声或旁白以及可见反应，不能替代观众已经看到或听到的证据，也不要与密集对白或快速动作挤在同一 Clip。

镜面、水面、玻璃和屏幕只有在物理位置、角度和光线成立时才能使用；反射仅作情绪辅助，不承担唯一剧情信息，也不得形成同一角色的清晰第二个身体。

## 9. 关键方法：摄影与表演选择

只选择能直接服务当前故事节拍的景别、镜头感觉和运动。同一 Shot 优先围绕一个主机位，通过推、拉、摇、移、跟随、焦点转移或人物进入/离开画面完成兼容变化；需要硬切到另一个独立机位、跨越既定轴线或让远端角色突然成为近端前景时，在相邻 Clip 之间建立新的 Shot 边界。单个 Clip 内不得包含这类互不兼容的切换，生图前 Clip 承载预检必须提前拆开。

| 故事需要 | 优先选择 |
|---|---|
| 交代地理、路径或群体关系 | 大远景、全景、深焦或克制跟拍 |
| 对话、倾听与姿态 | 中景、中近景、标准镜头或过肩覆盖 |
| 决定、识别、伤口或隐忍 | 特写、长焦、浅景深或受控推近 |
| 证据、手部和关键道具 | 插入镜头；微距仅在触感确实重要时使用 |
| 孤立、失败或环境揭示 | 拉远、宽景或增加负空间 |
| 急迫、追随目标或发现关系 | 跟拍、摇摄或克制手持 |
| 控制、正式或压迫 | 静态、居中、低角度或前景遮挡 |

演员运动必须改变关系或状态：走近表示挑战或急迫，远离表示拒绝或隐藏，坐下或站起表示权力变化，转身表示回避或计算，触碰物件表示证据、犹豫或自控。没有戏剧变化时保持克制，不用无目的移动填充画面。

## 10. 关键方法：同集 Shot 连续性交接

同一集的不同 Shot 即使并行生成，也必须先按剧本顺序建立连续性链。同场连续与明确转场使用不同的继承方式：

1. 按顺序记录每个 Shot 的场景、时间天气、光线、摄影机所在侧、银幕方向、角色站位、身体状态、道具归属和环境底声。
2. 每个场景的第一个 Shot 使用该场景固定设定，并从剧本和导演规划读取人物、道具及声音的进入状态。同一场景且没有明确转场时，后续 Shot 的 `承接状态` 继承上一 Shot 的 `交接状态`。
3. 剧本明确切换地点、时间或视角时，下一 Shot 改用新场景固定设定，只继承剧情要求跨场延续的人物身体状态、服装、道具归属、关系状态或持续声音。是否表现可见转场由剧本和导演规划决定，不强制补拍移动过程。
4. 没有剧本依据时，同一场景的空间结构、家具、门窗、光线、服装、道具归属和人物数量不变；景别变化仍保持轴线、视线和空间关系。
5. 多人、移动、近身动作或相似角色等高风险 Shot，只记录维持连续性必需的站位、路径、动作对象、道具状态和保持不动者。角色发生移动时按一个连续身体完成动作，不把不同时刻的位置同时生成在画面中。
6. Shot 边界优先落在完整台词、声音事件或自然停顿后；跨 Shot 的连续声音必须在前后 Prompt 中写清衔接。
