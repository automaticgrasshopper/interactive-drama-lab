# 业务接口声明

本文件是 `plan-storyboard-and-generate-video-biz` 与工程侧之间的字段合同。工程按这里声明的字段名称、类型和层级取值并写入对应数据库；`SKILL.md` 和其他 Reference 中的展示说明不能改变本文件定义。

## 接口规则

- 用户可见字段使用中文；文件名、URL、资产 ID、clip/shot 编号和接口必要参数可以保留英文或技术值。
- 字段名称必须完全一致，不使用同义词、旧字段或英文别名。
- `list` 表示有序列表，`object` 表示嵌套对象，`string` 表示自然语言字符串，`number` 表示数字，`boolean` 表示布尔值。
- 可选字段没有值时使用 `null` 或空列表，不虚构内容。
- `分集剧本`、`关联角色`、`关联场景`、项目文件中的 `视觉风格`、`视角`、`画面比例`均有效时，Skill 才可完整执行。
- 输入中的 `角色名称`、`场景名称`、`道具名称` 和对应 `ref_id` 必须来自项目文件；不要临时编造、改写或用 URL/文件名替代资产引用。
- 正式输出字段不包含图片 ID、视频 ID、故事板 ID、分镜 ID 等工程 ID 字段。Agent 将生成结果写入项目文件后，由工程侧注册为项目资产并返回可供 `@[]()` 使用的资产 `ref_id`；其他内部 ID 仍由工程侧维护。
- `关联角色.音色ID` 指向项目音色库中的绑定音色，用于在 prompt 中形成该角色的 `#[角色名](音色ID)` 声线引用；工程执行生视频任务时必须解析对应试听音频，并将其作为该角色的声音 Reference 实际传入。试听内容不要求与目标台词一致，不得因此跳过声音 Reference、生成静音视频、临时猜声或换声。
- `@[]()` 只引用项目资产 `ref_id`，统一写成 `@[资产名称](资产ref_id)`；不得填图片存储 ID、文件 ID、URL 或数据库主键。视频 Prompt 中已关联角色和已关联道具每次出现都必须使用完整 `@[]()`，不能只在首次出现时引用，后文也不能改用裸名称、代词或泛称。角色、场景、道具分别使用输入中的 `角色ref_id`、`场景ref_id`、`道具ref_id`；剧集故事板图片写入项目资产后，使用工程侧返回的故事板资产 `ref_id`。
- `分镜视频生成prompt.prompt列表.prompt文本` 中可以包含视频生成所需的 `@[资产名称](资产ref_id)` 和 `#[角色名](音色ID)` 引用 token；这些 token 是 prompt 文本内容，不是正式输出字段。
- 剧集故事板尚未取得项目资产 `ref_id` 时，不得生成依赖它的分镜视频 Prompt；先完成项目文件写入并取得 `ref_id`，不要用图片 ID 或 URL 代替。

## Skill 输入字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `视角` | string | 是 | 枚举：`第一人称`、`第三人称`。 |
| `画面比例` | string | 是 | 最终视频画面比例，例如 `16:9`、`9:16`、`1:1` 或明确自定义比例。 |
| `分集剧本` | string | 是 | 完整分集剧本，包含剧情、场次、行动推进、冲突、台词/心声和情绪转折。 |
| `剧本分析` | string \| object \| null | 否 | 基于剧本的补充信息，例如人物立场、情感变化、权力变化、信息差、关键线索和节奏重点。 |
| `关联角色` | list<object> | 是 | 本集出现的角色资产。至少包含本集主要出场角色；每项包含 `角色名称`、`角色ref_id`、`音色ID`。`音色ID` 可为空；有值时在 prompt 中使用对应声线引用，并把解析出的试听音频作为声音 Reference 输入生视频任务，不要求预先提供逐句对白音频。 |
| `关联场景` | list<object> | 是 | 本集涉及的场景资产。至少包含主要发生场景；每项包含 `场景名称`、`场景ref_id`。 |
| `关联道具` | list<object> | 否 | 本集出现的关键道具资产。无道具时使用空列表；每项包含 `道具名称`、`道具ref_id`。 |
| `视觉风格` | object | 是（工程注入） | 工程从项目文件读取并注入的项目级唯一、只读画风和固定风格 prompt；首次生成、局部重试和重新生成均原样复用。缺失时返回“项目画风配置缺失”并停止相关生成。 |
| `游戏企划` | object \| null | 否 | 项目级结构信息，用于辅助理解整体剧情。 |

## Skill 输出字段

```text
剧集故事板 object
└─ 故事板图片 object
   └─ 图片URL string | null

分镜视频生成prompt object
└─ prompt列表 list<object>
   ├─ 分镜编号 string
   ├─ 分镜描述 string | null
   └─ prompt文本 string | null

分镜视频 object
└─ 视频列表 list<object>
   ├─ 分镜编号 string
   └─ 视频URL string | null
```

## 输出约束

- 顶层只允许 `剧集故事板`、`分镜视频生成prompt`、`分镜视频`。
- `分镜拆分计划` 只能作为内部过程结果，不进入正式输出。
- `分镜视频生成prompt.prompt列表.prompt文本` 存完整 prompt，不拆 `prompt模块`、生成参数或 reference 明细；尚未生成或生成失败时为 `null`。
- `分镜视频生成prompt.prompt列表.分镜描述` 是面向创作者的故事化短叙述，不是 Prompt 摘录、制作说明或任务状态；具体写法以拆分指南为准。
- `分镜编号` 是由拆分顺序生成的稳定业务序号，不是数据库 ID；同一个 shot 在 `prompt列表` 和 `视频列表` 中必须使用同一编号。
- `prompt列表` 和 `视频列表` 长度、顺序与 `分镜编号` 必须始终一一对应；每个 `prompt列表` 条目包含非空 `分镜描述`，尚无可用 Prompt 时 `prompt文本` 为 `null`。
- 不输出顶层或条目级 `生成状态`。`prompt文本 = null` 表示尚无可用 Prompt，非空表示 Prompt 已完成且可使用；`视频URL = null` 表示尚无可用视频，非空表示视频已生成并可使用。`分镜描述` 不承担 Prompt 或视频状态判断。
- 排队、生成中、失败和重试等细粒度任务状态由工程任务层维护，不属于本 Skill 的正式输入输出字段。
- 生成参数、文件名、宽高、封面、失败原因、质量校验、reference 明细和拆分依据都不进入正式输出字段；如需保存，使用独立运行日志。
