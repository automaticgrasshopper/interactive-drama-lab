# 故事板提示词流程

本文件只负责把已经完成且通过生图前 Clip 承载预检的剧集导演规划组装成 `剧集故事板图片生成提示词`。执行时读取 `director-guide.md` 的“1.1 剧集故事板阶段”和完整导演规划；输入中的剧情、Clip 顺序、Clip 数量、人物调度、空间关系、摄影轴线、声音落点和代表性定格状态必须已经确定并锁定。缺少、互相冲突或尚未通过预检时，返回导演规划阶段补齐，不在提示词组装或生图阶段临时重新规划。

最终 Prompt 必须严格按以下顺序编写。前一部分没有写完整，不进入下一部分。

## 步骤一：先写版式与视觉系统

最终 Prompt 的开头先锁定整张故事板的版式和视觉系统，避免后续剧情内容挤掉或改写版式要求。

1. 明确生成一张横向 `16:9` 的高分辨率剧集故事板，优先达到 1080P 清晰度，无法稳定生成时可接受 720P。
2. 一级板块固定按以下顺序和位置出现：
   1. 顶栏：故事板编号、剧集标题、Clip 数量。
   2. 左侧参考栏：人物身份锚点、道具状态、场景空间锚点、导演规划中已经要求的俯视空间示意图、简短人物连续性说明。
   3. 中部故事板网格：按编号顺序排列的 Clip 画格。
   4. 底部信息条：音频与音调、灯光/情绪/风格、摄影说明、必要限制。
3. Clip 画格按实际数量自适应排列，不固定行数、列数或画格数量；画格比例尽量贴近输入 `画面比例`，同时保持尺寸规则、间距稳定和整板内容可读，避免极高、极宽或细长画格。
4. 画格编号与短标签使用固定位置并放在画格边框外，不覆盖电影画面。左侧参考栏只出现一次，不在其他区域重复同一组资产锚点。
5. 使用以下固定视觉系统，不自行替换配色或装饰体系：
   - 画布背景：深墨蓝黑 `#101820`。
   - 顶栏和板块标题：深蓝黑 `#13202A`。
   - 主要内容卡片：暖象牙白 `#F7F0DF`。
   - 标题文字：暖象牙金 `#F7E9C4`。
   - 正文：炭黑 `#1A1A1A`。
   - 元信息：灰蓝 `#6B7280`。
   - 强调色：克制哑金 `#C8A15A`。
   - 风险或错误强调：暗红 `#B55454`，只在必要处使用。
6. 同一项目保持相同的标题层级、边距、画格边框、圆角、标签位置和底部信息条样式；不使用随机渐变、紫色标题条、纯白整板背景或新的装饰体系。
## 步骤二：写整图任务与基础信息

1. 使用用户输入的主要语言编写完整 Prompt、板块标题、Clip 短标签、资产说明和台词/心声提示。多语言输入以分集剧本正文和用户明确要求为准。
2. 中文项目不使用英文模板板块名；仅保留必要的资产 ID、文件名、URL 和稳定编号。
3. 故事板编号使用 `EP{两位集数}-BOARD`，例如 `EP01-BOARD`。
4. Clip 编号使用 `EP{两位集数}-C{两位序号}`，例如 `EP01-C01`、`EP01-C02`。重新生成同一集时沿用原编号。
5. 写入输入的 `视角` 和 `画面比例`，将其作为所有 Clip 的构图约束，但不把这两个字段显示在故事板顶栏或 Clip 标签中。
6. 完整透传项目文件中的 `视觉风格`，不缩写、不改写、不替换，也不重新向用户确认。

## 步骤三：写资产锚点

1. 按 `business-interface.md` 读取并写入本集实际使用的 `关联角色`、`关联场景` 和 `关联道具`，资产名称与 `ref_id` 必须一一对应。
2. 每个角色只建立一次身份锚点，写清脸、年龄感、发型、体型、服装和标志性配饰。角色设定图中的正面、侧面、背面、特写和细节都表示同一角色，不是多个演员。
3. 场景锚点使用纯场景空景，只呈现建筑结构、门窗、主要家具、不可穿越物和稳定空间关系；人物仅出现在人物身份锚点和对应 Clip 画格中。道具锚点写清外观、材质、归属角色和当前状态。
4. 导演规划已经要求俯视空间示意图时，将其写入左侧场景参考区，只表现空间边界、不可穿越物、可行走区域、必要路线节点、主要摄影机位置、拍摄类型和对话轴线，并保持为无人空间规划图。
5. 不在这一部分新增角色、场景、道具、空间路线或人物调度；发现导演规划与资产不一致时，返回上一步修正。

## 步骤四：按导演规划写每个 Clip

1. 按导演规划中的原始顺序逐一写入所有 Clip，不新增、删除、合并、拆分或重排。
2. 每个 Clip 固定按以下顺序写：
   - 稳定编号和一条简短标题。
   - 代表性定格画面：本帧可见角色、当前站位、身体朝向、视线对象、动作对象、道具当前状态和场景关系。
   - 可见表演：呼吸、眼神、眉眼嘴角、手部、肩颈、身体距离或与道具的关系，并写清情绪方向与克制程度。
   - 本 Clip 的关键剧情发展和实际存在的关键台词/心声；没有台词时不强行添加。
   - 导演规划已经确定的景别、机位或摄影感觉。
3. Clip 画格只描述一个明确时间点和当下已经可见的状态，不写动作的起点、过程和终点，不把多个时间状态塞进同一画格。
4. 把抽象情绪落实为可见状态，不能只写“紧张”“悲伤”“愤怒”等情绪名；表情强度服从剧本，不夸张表演。
5. 多人、救援、搀扶、争抢、拥抱、格斗或对峙等高风险 Clip，使用正向的单帧角色清单：只列出本帧应当可见的命名角色，每名角色只写一次，并分别写清唯一的当前站位、身体朝向、视线、动作对象和当前职责。普通 Clip 不逐格重复人物唯一性口号或完整身份字段。
6. 每个画格只显示稳定编号、一条短标签和必要短句；详细画面要求用于指导生图，不作为大段可见正文排进画格。
7. 故事板不显示 Clip 秒数、时间码或整集预计时长。

## 步骤五：写连续性与空间约束

1. 将导演规划中已经确定的人物、道具、场景和对话轴线连续性整理成一段简洁约束，不重新推演剧情。
2. 相邻 Clip 的人物在场情况、当前站位、身体朝向、视线、道具归属与状态、场景陈设和对话轴线必须能够连续对应；没有剧情依据时不得跳变。
3. 单个 Clip 为每个命名角色建立一个可见实例，该实例承担本帧唯一的当前站位、朝向、视线、动作对象和职责；镜面、水面、玻璃或屏幕只保留不具备角色身份辨识度的环境反光。
4. 人物与摄影机必须遵守场景中的可行走区域、实体障碍和对话轴线，不得穿过墙、门、桌、床、柜台、沙发、栏杆或其他实体物。
5. 俯视空间示意图中的规划符号只属于左侧参考区，不得进入电影画格。

## 步骤六：写干净 Reference 限制

1. 电影画格、场景缩略和角色/道具参考图内不出现箭头、路线线、虚线、红框、圈注、运动轨迹、镜头轨道线、UI、字幕、说明文字或其他非戏内图形。
2. 画格编号、短标签和必要短句只放在画格边框、标题栏或画格外，不覆盖电影画面。
3. 路线、轴线和机位符号只允许出现在导演规划已要求的俯视空间示意图中。

## 步骤七：检查最终 Prompt

提交前只检查 Prompt 文本，不检查生成图片：

1. 最终 Prompt 是否以完整的版式与视觉系统要求开头。
2. 导演规划中的每个 Clip 是否按原编号、原顺序且只出现一次，没有遗漏或重新规划。
3. 每个 Clip 是否只描述一个定格状态，且关键剧情、台词/心声、视角和可见表演均已落实。
4. 关联角色、场景、道具和 `ref_id` 是否与项目文件一致；场景锚点与俯视空间示意图是否保持为无人空间。
5. 人物、道具、空间和对话轴线的连续性是否与导演规划一致；高风险 Clip 是否用正向单帧角色清单明确了每个命名角色的唯一可见实例和当前空间关系。
6. 板块顺序、固定色板、画格样式和干净 Reference 限制是否完整写入，没有被后续剧情内容覆盖。
7. 顶栏和 Clip 标签是否没有时长、时间码、比例、视角、详细正文或独立导演备注。
