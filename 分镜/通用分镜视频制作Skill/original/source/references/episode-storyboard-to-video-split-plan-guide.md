# 剧集故事板 clip 到 shot 拆分与视频生成指南

本指南分两个使用时机：“生图前 Clip 承载预检”在剧集故事板生图前执行；其余 Shot 拆分与视频 Prompt 章节在剧集故事板生成并发送到当前对话后执行。Shot 拆分读取 `director-guide.md` 的“1.2 Shot 拆分阶段”，视频 Prompt 读取“1.3 视频 Prompt 阶段”；两者都继承完整导演规划，并同时读取 `分集剧本` 与当前剧集故事板。

## 0. 生图前 Clip 承载预检

本预检只用于在故事板生图前定稿 Clip 清单，提前处理单个 Clip 内容过载及其引发的故事板返工。它只输出内部的“通过”或“需要拆分”判断，不制定 Shot 组合，不生成分镜编号、建议时长、时间码或视频 Prompt。

1. **核对完整覆盖**：按剧本顺序将每个剧情事件、关键台词/心声、线索、互动选择、关系变化和情绪转折映射到一个或多个 Clip；任何内容都不能只存在于摘要而没有对应 Clip。
2. **列出单 Clip 的完整承载内容**：对每个 Clip 汇总其对应的完整台词/心声、必须按物理顺序发生的动作、关键反应与停顿、道具状态变化和空间变化。这里读取完整剧本原文，不用短标签代替内容量。
3. **做承载判断**：判断上述内容能否由一个最长 15 秒的下游 Shot 以自然语速、完整动作和必要反应完成。只判断“可以自然承载”或“需要拆分”，不为 Clip 预测、标注或展示具体秒数。
4. **在生图前拆开超载 Clip**：出现完整对白或心声无法自然说完、多个必须串行的物理动作无法完成、多个独立戏剧状态被塞进同一画格，或需要多个互不兼容的定格构图时，按剧本中的自然动作、问答、揭示、反应或选择落点拆成多个连续 Clip。每个新 Clip 仍只对应一个代表性定格状态。
5. **检查相邻定格连续性**：逐对比较相邻 Clip 的在场人物、当前站位、身体朝向、视线、道具归属与状态、场景陈设和对话轴线；没有剧情依据的跳变先在导演规划中修正。
6. **锁定后再生图**：重复上述检查，直到全部剧本内容被覆盖、每个 Clip 均可自然承载且相邻定格连续，再锁定 Clip 编号、数量和顺序并进入故事板 Prompt 组装。预检不得为了少生成视频而压缩剧本、加速台词、删减动作，或提前把多个 Clip 规划为 Shot。

## 1. 执行门槛

1. 剧集故事板图片已经生成并发送到当前对话。
2. 拆分时同时读取完整导演规划、`分集剧本` 和当前剧集故事板。`分集剧本` 是剧情语义来源；导演规划提供导演方案；剧集故事板提供可视化 Clip 顺序和定格状态，不提供秒数。
3. 当前故事板作为固定拆分输入。拆分计划缺少必需字段、使用非相邻 Clip、无法追溯剧本依据或未覆盖剧本内容时，只修正拆分计划。分集剧本、关联资产或故事板要求发生变化时，按 `SKILL.md` 生成并发送新版故事板，后续流程使用最新版本。

## 2. Shot 拆分步骤

1. **建立有序 Clip 清单**：同时读取完整导演规划、`分集剧本` 和当前剧集故事板，按顺序为每个 Clip 对齐剧情事件、关键台词/心声、连续声音、因果与互动节点、人物站位、道具状态、空间调度、摄影轴线，以及相对于前后 Clip 的连续关系。后续只能处理相邻 Clip，不跨越顺序。
2. **标记硬边界**：逐一检查每两个相邻 clip 之间是否存在必须切开的边界。以下任一条件成立时标记硬边界：
   - 时间或地点跳变，且剧本没有连续转场动作。
   - 视角、主观角色、摄影轴线或画面逻辑明确切换。
   - 出场人物集合、人物位置、关键道具状态或门槛状态无法通过连续物理过程成立。
   - 合并后的最低自然表演时长超过 15 秒。
   - 长距离跨空间、多门槛穿越、人物身份或关键状态无法在一次连续生成中稳定维持。
   - 剧本明确需要切镜完成信息隐藏、揭示、反应落点、时间压缩或互动节点。
   - 覆盖相邻 Clip 必须硬切到独立机位、改变摄影机所在侧，或把远端角色重新布置为近端前景，无法通过一个主机位及兼容的连续摄影运动完成。
3. **在硬边界区间内向后合并**：从区间第一个 clip 开始，依次尝试加入后一个相邻 clip。满足以下全部条件时继续合并：
   - 处于同一时空，使用同一视角规则和兼容的摄影轴线。
   - 主要出场角色稳定，站位或移动路径可以连续解释。
   - 前一 clip 的动作、台词、问题、视线、声音或道具状态直接引出后一 clip 的回应、结果或反应。
   - 同一句台词、心声、环境底声或连续声音事件跨越两个画面状态时，合并后可以保持一条不中断的声音轨。
   - 合并后仍围绕一个宏观戏剧目标，建立、行动、反应和落点可以作为目标内的多个微节拍连续完成。
   - 合并后的自然表演时长不超过 15 秒，也不需要用剧本外动作填充。
   - 合并后的画面可由一个主机位和兼容的连续摄影运动承载，不依赖多个独立机位之间的硬切或演员重新站位。
4. **关闭当前 Shot**：遇到硬边界，或下一 clip 不满足全部合并条件时，结束当前 shot，并从下一 clip 开始新 shot。单个 shot 可以包含一个、两个、三个或更多相邻 clip；clip 换格、景别变化、连续台词或自然的“建立 -> 行动 -> 落点”结构都不单独触发关闭。
5. **处理高风险连续动作**：移动、进出门、精确道具状态、多人近身、反射或复杂空间只触发稳定性评估，不自动拆分。能够用清晰路径、固定站位和连续表演完成时保留在同一 shot；无法成立时回到步骤 2 增加硬边界。
6. **建立 Clip -> Shot 唯一映射**：为故事板中的每个 Clip 建立且只建立一条映射记录，值为唯一的 Shot 编号。按原始 Clip 清单逐项比对映射结果的数量、顺序与覆盖范围；任一 Clip 缺失、重复映射、跨 Shot 复用或顺序错位时，拆分计划不通过，不能初始化槽位、生成 Prompt 或启动视频。
7. **校验拆分结果**：确认每个 Shot 的剧本依据均完整交付，建议时长在本阶段根据实际台词、动作、反应和停顿独立计算。按 `director-guide.md` 的“同集 Shot 连续性交接”检查同场继承与明确转场，并确认连续声音没有因 Shot 边界被无意截断。单个来源 Clip 无法在 15 秒内自然承载属于第 0 节必须提前发现的问题，不作为常规返工分支；不得强行复用同一 Clip、删减内容、加速台词或用剧本外动作填充。分集剧本、关联资产或故事板要求发生变化，或者用户明确要求修改故事板时，生成并发送新版故事板，后续流程使用最新版本。

## 3. 分镜拆分计划字段

每个 shot 至少包含：

- `分镜编号`：稳定编号，例如 `EP01-SHOT01`、`EP01-SHOT02`。`SHOT` 表示用户可感知的分镜。
- `标题`：短标题，描述本 shot 戏剧功能。
- `分镜描述`：一至两句故事化短叙述，按剧情发生顺序讲清人物的行动、对白或声音和情绪变化；它是给创作者阅读的剧情文本，不是 Prompt 摘录或制作说明。
- `来源 clip 范围`：例如 `EP01-C03~EP01-C05`。
- `来源 clip 编号`：按顺序列出。
- `剧本依据`：列出本 shot 覆盖的原剧本事件、关键台词/心声、关系变化、线索、互动选择和情绪转折；不要只写来源 clip。
- `剧本覆盖校验`：说明来源 clip 范围内对应的剧本内容是否全部覆盖；若遗漏，写明需要回到剧集故事板补齐或需要重新拆分。
- `建议时长`：秒数，来自台词、动作、停顿和情绪节奏。
- `内容量与时长匹配`：列出台词/心声长度、关键动作数量、必要反应点、最低可表演时长、建议时长和匹配结论；如果装不下，先拆 shot 或调整来源 clip 范围。
- `连续价值`：为什么这些相邻 clip 适合组成一个 shot。
- `边界判定`：说明本 shot 内部的 clip 为什么不需要切开，以及与前后 shot 之间为什么必须切开；不得只写“clip 不同”或“便于生成”。
- `不继续拆分原因`：为什么本 shot 已经足够稳定；如有高风险，则说明应进一步拆分。
- `逐 clip 映射`：每个来源 clip 对应的视频时间位置、关键状态、动作、台词/心声和状态到达点；剪辑触发点仅在确实需要剪切时填写。
- `人物与空间连续性`：本 shot 涉及的命名角色、身份锚点、主要站位和动作状态；仅在移动、多人近身、进出门或相似角色高风险片段中写清起点、终点、固定观察者和空位关系。
- `声音连续轨`：按发生顺序列出完整台词、心声、环境底声、动作声、音乐、沉默及重叠关系；标明哪些声音跨越画面切换，不能按 Clip 边界重复或截断。
- `承接状态`：本 Shot 使用的场景固定设定，以及从上一 Shot 或剧本明确进入状态继承的人物站位、身体状态、可移动道具归属和持续声音。
- `交接状态`：本 Shot 结束时留给下一 Shot 的同一组状态，以及确有剧情依据的变化。
- `空间规划继承`：若剧集故事板含俯视空间示意图，列出本 shot 继承的合法移动路径、不可穿越物、摄像机位置、对话轴线和沿路线拍摄类型。
- `观众必须看懂什么`：一句话写清本段交付的信息。
- `信息如何传达`：通过台词、动作、道具、反应、声音、后期字幕或 UI 层交付。
- `看不懂时的补救方式`：若音频、字幕或动态文字不可靠，备用交付方式是什么。
- `视频 Reference`：固定包含剧集故事板图片；可包含关联角色图和关联道具图；只要出场角色存在 `音色ID`，就必须包含由该 ID 解析出的音色库试听音频，并绑定到对应角色。不得包含单独关联场景图。

## 4. 节拍与时长

故事板不提供时长。本阶段必须从 `分集剧本` 和当前 shot 的实际内容重新计算建议时长，并先按 `director-guide.md` 的“对话与声画关系”确定完整声音范围及其覆盖的画面，再据此拆分时间轴。不要机械填满 15 秒上限，也不要压缩到台词说不完。以下时长区间只用于完成方案后的诊断，不是按内容类型直接分配秒数的模板：

- 0.8-1.5 秒：建立信息、道具插入、反应闪现、动作标点。
- 1.5-2.5 秒：一句短台词、一个眼神、一个物件动作、小幅移动。
- 2.5-4.0 秒：短入场、姿态变化、动作加反应、短问答。
- 4.0-6.0 秒：简单连续行动，有清晰起点、路径和终点。
- 6.0-9.0 秒：紧凑对话交换，或行动加一个明确反应。
- 9.0-15.0 秒：只用于一个连续、空间稳定、目标明确的动作，不用于多个彼此独立的宏观戏剧目标集合。

如果故事动作只需要 5 秒，不要为了时长上限生成 15 秒。过长时长容易产生额外行走、额外空间、重复动作或多余停顿。

### 时长计算步骤

每个 shot 在写 `建议时长` 和视频 Prompt 前，按以下顺序计算：

1. **列出完整内容**：逐项列出本 shot 必须交付的剧情事实、关系变化、线索、互动选择、情绪转折、完整台词/心声和动作任务，不用摘要替代原文。
2. **估算声音轨**：先按导演指南确定每句对白、心声和重要声音的完整连续范围及画面覆盖，再按角色实际语气、情绪强度、句法停顿和音色试听中的自然说话节奏估算时长；保留完整说话时间，不以画面切点截断，也不以统一字数公式强行压缩。
3. **估算动作轨**：按物理顺序估算位置变化、门槛穿越、道具状态变化、身体接触、救援/争抢/交接和必要表情变化；不能瞬间完成的过渡必须占用时间。
4. **安排反应与落点**：只为关键理解、关系变化、情绪转折或悬念安排倾听反应、呼吸、沉默、视线、手部动作或道具声；普通台词不机械追加固定停顿。
5. **合并并行内容**：自然同时发生的台词、视线、表情、手部动作、环境声和小幅移动使用同一时间段；存在先后因果的动作、回应和状态变化依次相加。
6. **确定建议时长**：以完整声音轨和动作轨中较长者为基础，加上必须串行发生的反应、转场和落点；多出的时间如果没有新的视觉、声音、关系或情绪变化，直接缩短。
7. **检查 15 秒上限**：超过上限时在相邻 clip 的硬边界或自然戏剧落点拆成更多 shot，并分别重新计算；不得删台词、加速到不自然语速或省略动作过程。
8. **生成两条同步时间轴**：从 `00:00` 开始，分别规划画面时间轴与台词和声音时间轴。两条时间轴总时长必须与建议时长一致，但分段边界不必对齐；一句持续对白或环境声可以跨越多个画面时间片。

只有以下情况才触发拆分：

- 出现第 2 节定义的硬边界。
- 一个 shot 包含多个彼此独立、不能由同一连续表演串联的宏观戏剧目标。
- 连续台词、心声、动作或反应无法在 15 秒内自然完成。
- 空间移动、关键对话、道具状态变化和情绪转折无法在一个清晰物理过程与摄影方案中同时成立。
- 为了讲完内容必须加快台词到不自然速度，或为了填满时长必须添加剧本没有的动作。

详略安排规则：

- 每个 shot 只围绕一个连续戏剧目标安排详略；可以包含建立、动作、问答、反应和落点等多个微节拍，只要它们共同完成同一目标。
- 过桥信息可以用一句短台词、一个道具动作或一个反应完成，但不能省略剧本要求观众理解的事实、因果或情绪变化。
- 如果剧集需要解释世界观、身份、关系和任务，按“触发 -> 反应 -> 一句确认 -> 新目标”分散到多个片段，不要集中成连续口播。
- 情绪转折和选择压力需要留白；纯设定说明不需要长停顿。

镜头覆盖、人物调度、同集连续性、声画关系、情绪摄影及对话、群像、救援、调查、动作等方法，按 `director-guide.md` 的“1.2 Shot 拆分阶段”及其引用章节执行；本指南只负责把既定导演方案转换为 Shot 边界、时长与工程字段。

## 5. 视频 Prompt 编写流程

视频 Prompt 使用过程调度语言，并读取 `director-guide.md` 的“1.3 视频 Prompt 阶段”、完整导演规划和拆分计划。它把剧集故事板 Clip 中的定格画面严格按照分集剧本组织成连续片段，不重新规划故事板。可以描述移动路径、动作先后、镜头跟随、道具递交/放下/拿起和首末状态；画面调度继承故事板与导演规划，声音调度继承独立声音连续轨。若拆分计划缺少 `剧本依据`、`剧本覆盖校验`、`承接状态` 或 `交接状态`，不得撰写视频 Prompt。

视频 prompt 是直接执行指令，不是拆分计划、导演分析或质量报告。写入 Prompt 前必须完成一次“分析转执行指令”清洗：

- `剧本依据`、`剧本覆盖校验`、`连续价值`、`边界判定`、`不继续拆分原因`、`观众必须看懂什么`、`信息如何传达`、`看不懂时的补救方式`、风险判断和内容量分析只用于内部规划，字段名、结论和解释不得进入最终 Prompt。
- 把必须落实的内部结论改写成摄像机可拍、演员可演、麦克风可收或可验证的具体指令。只写最终要发生什么，不解释为什么这样安排。
- 删除“为了表现”“用于传达”“观众需要明白”“本镜头的目标是”“象征”“体现”“说明了”“风险在于”“作为补救”等分析视角句式。
- 如果一条分析无法转换成明确画面、动作、台词、声音或状态约束，就不要写进 Prompt；回到拆分计划解决，不用抽象解释占据生成指令。

Prompt 必须按固定模块输出，顺序严格固定为：`参考故事板`、`画面时间轴`、`台词与声音`、`视觉风格`、`必要约束`。`参考故事板`、`视觉风格` 和 `必要约束` 使用 `模块名：内容`；`画面时间轴` 和 `台词与声音` 分别按时间组织。每个模块单独换行展示，不要改成自由段落、英文技术字段或旧的方括号模块；不能合并、删除、重命名或调换模块。

`画面时间轴` 使用以下固定层级：

- 写格式前，先根据场景或空间状态、机位或摄影运动、动作阶段、表情或人物关系状态的实际可见变化，形成当前 shot 的有序画面节拍序列；只在画面确实需要进入下一状态时建立新节拍。
- 画面时间片数量等于当前 shot 的实际画面节拍数量，可以是一段或任意多段，不设默认值；不得继承 Reference、格式说明、其他 Prompt 或历史结果中的时间片数量与切点。
- 对每个画面节拍依次输出一个时间片，先单独写时间戳 `[开始时间-结束时间]`；需要更精确时可使用小数秒。
- 时间戳下一层依次写 `- 场景与环境：...`、`- 景别与镜头：...`、`- 动作与表情：...`，三个子项缺一不可且顺序固定。
- 第一段从 `00:00` 开始，最后一段结束于本 shot 的建议时长；相邻时间片首尾相接，不留空档、不重叠。
- 写时间戳前先完成第 4 节的时长计算；任何画面动作、摄影或可见反应发生增删时，必须重新计算相关画面时间片，不能只改文字而保留旧时间戳。
- 台词句界、声音事件和固定秒数不决定画面时间片数量。
- 每个时间片只写该时段实际可见的场景、摄影和人物表演，不提前描述后续状态，也不重复已经结束的动作。

`台词与声音` 使用独立声音时间轴：

- 每条声音事件使用独立时间戳 `[开始时间-结束时间]`；声音时间戳与画面时间片边界可以不同，声音事件数量也不决定画面时间片数量。
- 一句跨越多个画面时间片的对白或心声只写一次，使用完整连续区间，不因画面切换拆句、重复、截断或重启。
- 每条台词/心声绑定说话角色、完整文本、语气、音色和自然停顿；角色已绑定音色时，同时使用角色 `@[]()` 和音色 `#[]()`。
- 环境底声、音乐和持续动作声可以覆盖整个 Shot；瞬时脚步、开门、物件碰撞等按真实发生时间单独标注。允许多个声音区间重叠。
- 声音可以先于对应画面进入，或在画面切走后延续；写清声音来源在画内或画外，以及它如何持续到下一画面。
- 声音时间轴从 `00:00` 覆盖到 Shot 建议时长。没有对白的区间也要以环境底声、动作声、呼吸、音乐或明确静默保持连续，不留无法解释的声音空档。
- 关键台词后的可见反应写在画面时间轴的 `动作与表情`，对应停顿、呼吸或物件声写在声音时间轴；两条轨道共享时间但不强制使用相同分段。

所有参考资产在 prompt 中使用统一引用格式：

- 图片资产：`@[资产名称](资产ref_id)`，例如 `@[EP01故事板](storyboard_ref_001)`、`@[苏晴](character_ref_001)`、`@[银戒](prop_ref_001)`。圆括号内只能使用项目资产 `ref_id`，不得使用图片存储 ID、文件 ID 或 URL。
- 音色：`#[角色名](音色ID)`，例如 `#[苏晴](voice_001)`，表示该角色使用项目音色库中对应的绑定音色。
- 视频 Prompt 中每次出现已关联角色或已关联道具，都必须完整写成 `@[资产名称](资产ref_id)`；该要求适用于 `景别与镜头`、`动作与表情`、`台词与声音` 和 `必要约束`，不能只在首次出现时引用，后续也不能退回裸名称、代词或“对方”“她”“他”等会隐藏资产身份的称呼。
- 角色同时存在音色时，在 `台词与声音` 中同时写角色图片引用和音色引用，例如 `@[苏晴](character_ref_001)使用#[苏晴](voice_001)说……`。`@[]()` 锁定角色视觉身份，`#[]()` 锁定该角色声线，二者不能互相替代。
- 未进入 `关联道具` 的普通布景物件不强制引用；承载剧情、被角色操作或需要保持一致的道具必须先取得真实 `道具ref_id`，再在每次出现时使用 `@[]()`。
- 名称只使用资产本身的名字，不额外添加“角色图”“道具图”“音色对应”等类型后缀。
- 方括号 `[]` 必须保留。不要写成 `@资产名称(资产ref_id)` 或 `#角色名(音色ID)`。
- 若图片资产缺少可用 `ref_id`，不要虚构或用图片 ID/URL 顶替；先把资产写入项目文件并取得真实 `ref_id`。音色缺少可用 `音色ID` 时同样不得虚构。

固定模块如下：

`参考故事板：` 只写剧集故事板，不写角色、道具、场景、风格、音频或其他资产。来源 clip 始终使用故事板中的完整标准编号：单个写 `EP01-C03`，连续范围写 `EP01-C03~EP01-C05`。模块写成“参考@[EP01故事板](故事板资产ref_id)的EP01-C03~EP01-C05生成视频”。剧集故事板生成后应先写入项目资产并取得 `ref_id`；不要使用图片 ID 或 URL。不要在本模块写画面比例、视角或建议时长。

`画面时间轴：` 依次覆盖本 shot 的完整时长。每个时间片内部按以下方法填写三个子项：

- `场景与环境`：继承来源 clip 在剧集故事板中已经确定的地点和空间规划，写清该时间片可见的场景类型、前中后景层次、入口与出口、关键家具或地形、不可穿越物、主要光源、时间天气、背景活动和环境状态。相邻时间片处于同一场景时，固定空间结构、陈设位置、光线方向和天气状态，只写剧情确实造成的变化；不得无依据新增、删除、移动或替换场景锚点。场景细节必须具体到足以维持空间连续性，但不把单独场景图加入视频 Reference。
- `景别与镜头`：只写该时间片的主景别、摄影机位置、运动方式、视线关系、构图状态和确有必要的剪辑触发点。一个 Shot 优先围绕一个主机位，用与当前轴线和演员站位兼容的连续摄影运动完成变化；相邻 Clip 之间需要硬切到独立机位、改变摄影机所在侧或重新布置演员时，返回拆分阶段建立新的 Shot。单个 Clip 内不得包含这类切换；生图前 Clip 承载预检必须提前将其拆开，视频 Prompt 不复用来源 Clip，也不临时重画故事板。不要写宏观戏剧目标、镜头作用、情绪分析或选择该摄影方案的理由。第一人称必须限定 POV，第三人称必须保持外部摄影机和空间关系。不要同时堆多个互不兼容的摄影方案。本子项出现已关联角色或已关联道具时，每次都使用完整 `@[]()` 引用。
- `动作与表情`：写清该时间片谁在场、谁移动、谁保持不动、谁观察、谁触碰道具，以及动作的起止状态。凡是本子项提到的已关联角色和已关联道具，每次出现都使用 `@[资产名称](资产ref_id)`；角色使用 `角色ref_id`，道具使用 `道具ref_id`，不得在后文改用裸名称、代词或泛称承接。可以写“从哪里到哪里”“先做什么再做什么”“物件如何被递交、放下或拿起”。写清不可穿越物、门/盒子/屏幕等状态物件的首末状态；只有在多人、移动、相似角色或近身动作高风险片段中列出人物与空间连续性。若剧集故事板含俯视空间示意图，继承其中的角色路径、摄像机位置、对话轴线和沿路线拍摄类型。

每个出现角色的表情描述必须同时包含 `情绪方向` 和 `情绪强度`，并落到当前时间片可表演的外部状态：眼神焦点与移动、眉眼和嘴角变化、呼吸速度、下颌或肩颈张力、身体距离、停顿及手部细节。强度使用低、中、高或等价的明确程度词，并结合剧情写成“轻微”“克制”“逐渐增强”“明显但仍受控”等可执行描述；只有剧本存在强烈爆发时才使用高强度。表情变化必须与该时间片的动作、台词或刺激同步，整体表演保持真实、细腻、不过量。

`台词与声音：` 按上述独立声音时间轴输出完整对白、心声和其他声音事件。说话角色每次都使用完整 `@[]()` 引用；角色已绑定音色时，同时用 `#[角色名](音色ID)` 标注声线 Reference，并把对应试听音频实际输入生视频环节。

`视觉风格：` 必填。直接从项目文件读取项目级唯一的固定风格 prompt，并在本模块中原文逐字透传。取得的 prompt 使用什么语言就保留什么语言，不受用户语言、分集剧本语言或其他 Prompt 模块语言影响；不得翻译、统一语言、摘要、改写、润色、重排、补充或删减任何内容，也不得附加临时风格词。不要把视觉风格图作为视频 reference。首次生成、局部重试和重新生成视频均复用同一份项目画风，不向用户询问或重新确认。

`必要约束：` 不重复来源 clip 范围；来源范围只在 `参考故事板` 模块中出现。只写本段必须保持的可执行状态和明确排除项，例如角色唯一性、固定站位、合法移动路径、道具归属与首末状态、禁止新增人物或禁止穿越实体。不得写观众理解目标、信息传达方案、补救思路、拆分理由、风险分析、剧情解释或导演意图。每条 prompt 在本模块统一写入一次成片排除约束：剧集故事板仅作导演规划 reference，最终视频不得出现整个故事板页面、多画格分屏、故事板版式、边框、板块标题、编号贴纸、标签、箭头、路线线、机位符号、红框、圈注、字幕、UI 标记、说明文字或俯视空间示意图。

### 分镜描述写法

- 在拆分计划确定时，根据 `分集剧本` 和本 shot 覆盖的连续剧情独立撰写，不等待视频 Prompt。
- 以讲故事的视角，按发生顺序描述人物做了什么、说了什么或听见了什么，以及随之发生的情绪变化；一至两句话即可，不写导演解释或信息交付分析。
- 不写“观众必须看懂”“本镜头传递”“戏剧功能”“用于表现”等制作意图，不保留 `动作与表情`、`台词与声音` 等模块名。
- 不包含 `@[]()`、`#[]()`、clip 范围、景别、机位、视觉风格、生成限制或其他技术信息。
- 不得从 `prompt文本`、剧集梗概、其他分镜描述或任何备用字段摘取、拼接、推导或回填。缺失时保持空值并报告字段缺失，不用其他内容代替。
- Prompt 生成、失败或重试都不改写描述；只有来源剧本或拆分计划变化时才重写对应描述。

格式契约：

```text
参考故事板：<故事板引用与来源 Clip 范围>
画面时间轴：
{按实际画面节拍数量依次重复以下区块}
[<开始时间>-<结束时间>]
- 场景与环境：<当前时间片的直接生成指令>
- 景别与镜头：<当前时间片的直接生成指令>
- 动作与表情：<当前时间片的直接生成指令>
台词与声音：
{按实际声音事件数量依次重复以下条目，时间区间独立于画面时间片}
[<开始时间>-<结束时间>]
- <当前声音事件的直接生成指令>
视觉风格：<项目文件中的固定视觉风格 prompt 原文>
必要约束：<当前 shot 必需的直接生成约束>
```

该契约只声明模块层级和重复单元，不代表一个固定时间片，也不提供默认段数、切点、人物、场景或剧情内容。

## 6. Reference 使用补充

- 音色锚点：若角色有 `音色ID`，在视频 Prompt 中同时使用角色的 `@[角色名](角色ref_id)` 和 `#[角色名](音色ID)`，并把解析出的试听音频实际输入生视频任务。试听内容不限定目标台词，音色只能绑定该角色，不能给其他角色、旁白、音乐或环境声使用。
- 资产锚点：图片资产使用 `@[资产名称](资产ref_id)`；角色、场景、道具分别取项目文件中的 `角色ref_id`、`场景ref_id`、`道具ref_id`，剧集故事板取写入项目资产后返回的 `ref_id`。视频 Prompt 中已关联角色和已关联道具每次出现都重复完整引用。音色使用 `#[角色名](音色ID)`。场景的 `@[场景名称](场景ref_id)` 只能用于故事板生成和文本场景约束，不得关联为视频 reference。

## 7. 音色 Reference 使用方法

`关联角色.音色ID` 表示角色绑定的音色库条目。相关 prompt 必须保留该角色的声线引用，执行生视频任务时必须解析并实际传入对应试听音频。

- 使用 `#[角色名](音色ID)` 标记角色与音色的绑定关系，并将该 `音色ID` 解析出的试听音频作为声音 Reference 输入对应的视频生成任务。
- 试听音频用于提供音色、年龄感、语气质地、语言和口音；视频模型应使用这条声线演绎 `台词与声音` 模块中的目标台词或心声，而不是把试听内容原样播放到成片。
- 试听内容不需要与目标台词逐字一致。两者内容不同不构成跳过声音 Reference、生成静音视频、临时猜声或换声的理由。
- 标准执行方式是把试听音频直接作为声音 Reference 随视频任务传入，由视频模型按 `台词与声音` 模块生成对应角色声音。
- 一个 `音色ID` 只能绑定一个角色；不得用于其他角色、旁白、环境声或音乐。
- 若 `音色ID` 无法解析到试听音频或试听文件不可访问，记录资源解析失败并保留对应结果占位为 `null`；不要静默改成文字音色描述、临时猜声、换声或静音生成。

## 8. 文本与 Prompt 检查清单

- `Clip -> Shot` 唯一映射已逐项通过：所有来源 Clip 按原顺序各出现一次，没有遗漏、重复、跨 Shot 复用或顺序错位；每个 Shot 只组合相邻 Clip，并能追溯到完整 `分集剧本`。
- Shot 边界符合第 2 节的硬边界与连续价值判断；建议时长按第 4 节重新计算，足以容纳完整声音、动作、反应和必要停顿。
- 同场继承、明确转场、人物调度、空间、道具和声音连续性符合 `director-guide.md`，没有为了并行生成而重新解释前后状态。
- 每条 Prompt 使用标准来源 Clip 编号并完整覆盖对应剧本内容；`画面时间轴` 与独立 `台词与声音` 时间轴连续覆盖 Shot 总时长。
- Prompt 模块、时间片层级及 `@[]()`、`#[]()` 引用符合第 5 至 7 节；视频 Reference 不包含单独关联场景图或视觉风格图。
- Prompt 只保留可拍、可演、可听或可约束的直接指令，不包含剧本依据、拆分理由、风险分析、观众理解目标或导演解释。
- `分镜描述` 按本文件独立撰写，不摘取或复述 Prompt，也不包含制作字段或技术信息。
